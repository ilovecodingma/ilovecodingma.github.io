外国人可参加的韩国征集活动：如何查找与参加

发布日期 2026-10-27

韩国的公共机构、城市和企业每月举办数百场征集活动（공모전）——摄影、短视频、征文、口号、创意和设计——其中许多设有现金奖励。相当一部分允许外国居民参加。本页讲解如何读懂参赛资格一栏，并列出本站目前开放中、且规则提到外国人的征集活动。下方的列表每小时自动更新。

如何读懂参赛资格栏（응모자격）

韩文表述含义外国人可以参加吗？
누구나 / 제한 없음任何人／无限制通常可以——但要确认其他地方没有国籍方面的限制
내·외국인 누구나韩国人和外国人均可可以
국적 무관不限国籍可以
등록외국인 포함 / 국내 거주 외국인 포함包括登记外国人／在韩居住的外国人可以，前提是你持有外国人登记证
대한민국 국민大韩民国国民不可以，除非括号内另行加入外国人
○○시민 / 도민某市或某道的居民如果你的登记住址在该地，通常可以

操作步骤

  1. 在官方公告中找到 응모자격 一行，对照上表逐词翻译。
  2. 查看奖励部分（시상）中关于税的说明：奖金是在扣除韩国预扣税之后发放的，通常需要提供你的外国人登记号码。
  3. 查看提交格式。许多征集活动只接受韩文作品；视频和摄影类征集通常没有语言要求。
  4. 查看版权条款（저작권）。有些主办方会保留获奖作品的权利。
  5. 如果措辞不清楚，请在提交前给主办方发邮件询问，并保存好回复。

常见问题

我必须用韩文写作吗？
视具体活动而定。摄影、视频和设计类征集很少要求韩文文字；征文和口号类通常要求。
我可以和韩国朋友组队参加吗？
通常可以，只要每位成员都符合参赛资格一栏。发放奖金时往往使用队长的信息。
F-4 或 D-2 签证会有问题吗？
征集活动很少按签证类型设限，但领取奖金属于收入；如果你不确定自己的签证是否允许，请咨询出入境外国人综合服务中心（1345）。
