📤 제출 순서

  1. 공식 공고를 열어 자격·마감 시각·제출 규격을 확인해요.
  2. 규격(분량·길이·파일 형식·파일명)에 맞춰 제출물을 만들어요.
  3. 접수합니다 — 자동 분류상 「이메일 접수(공고 확인)」 방식이에요. 실제 접수는 위 「공식 공고·접수 페이지 열기」 버튼이 여는 주최 측 페이지와 공고를 따르세요.
  4. 접수 완료 메일이나 화면을 저장해 두고, 수정 가능 기간을 확인해요.
