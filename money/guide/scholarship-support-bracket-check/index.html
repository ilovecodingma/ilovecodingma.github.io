내 학자금 지원구간은 어떻게 정해지고, 어디서 확인하나요?

🗓 확인일 2026-10-26📎 공식 출처 3곳☎ 한국장학재단 상담센터 1599-2000
3줄 요약
  1. 학자금 지원구간은 우선적 학자금 지원 대상자를 고르려고, 학생 가구의 소득·재산을 조사해 산정한 소득인정액을 재단의 구간표에 적용해 정한 값이라고 한국장학재단 안내 페이지에 적혀 있어요.
  2. 이 글은 구간 금액이 아니라 구간이 정해지는 절차와 확인·최신화 방법만 다뤄요.
  3. 국가장학금 종류와 신청은 국가장학금 가이드를, 대출 상환은 학자금대출 상환 가이드를 보세요.

기준: 한국장학재단 누리집 '학자금 지원구간' 안내 페이지(kosaf.go.kr), 한국장학재단 설립 등에 관한 법률 시행령(국가법령정보센터) · 줍줍 확인일 2026-10-26 · 원문 바로가기: 한국장학재단 학자금 지원구간 안내 · 한국장학재단 · 한국장학재단 설립 등에 관한 법률 시행령

⚠️ 먼저 읽어 주세요

구간별 소득인정액 경곗값은 학기마다 달라질 수 있다고 안내 페이지에 적혀 있고, 줍줍은 올해 경곗값 표를 읽지 못했어요. 정확한 구간은 한국장학재단 로그인 화면이나 상담센터에서 확인하세요.

1지원구간이 정해지는 순서

단계안내 페이지에 적힌 내용확인 상태
1. 학자금 지원 신청학생 본인이 홈페이지 또는 모바일로 신청해요공식 페이지 확인
2. 정보제공 동의학생, 부모 또는 배우자가 재단 홈페이지, 모바일, 웰로(Wello)에서 동의해요공식 페이지 확인
3. 소득·재산 조사보건복지부 사회보장정보시스템을 통해 조사해요공식 페이지 확인
4. 학자금 지원 결정재단이 결정해요공식 페이지 확인
5. 최신화 신청해당자에 한해 홈페이지 또는 모바일로 신청해요공식 페이지 확인

2소득인정액과 구간 (산정 방식)

항목내용확인 상태
소득인정액 공식소득인정액 = 소득평가액 + 재산의 소득환산액 - 형제·자매 수에 따른 공제액 (안내 페이지 표기)공식 페이지 확인
구간 묶음안내 페이지에는 1~3구간 '가', 4~6구간 '나', 7~8구간 '다', 9구간 '라', 10구간 '마'로 묶인 표가 있고, 국가장학금 1유형 기준 가 600만원, 나 440만원, 다 360만원, 라 100만원, 마 미지원으로 적혀 있어요. 이 표가 어느 학기부터 적용되는지는 줍줍이 확정하지 못했어요적용 시기 미확인 · 기관 확인
구간별 경곗값(0~10구간 금액)구간별 경곗값은 학기마다 달라질 수 있다고만 읽었고, 금액표는 읽지 못했어요미확인 · 기관 확인
국외 소득·재산 신고 대상자위 절차와 다르며 '국외 소득·재산 신고제 안내' 메뉴를 확인하라고 적혀 있어요공식 페이지 확인

3가구원 동의와 서류

상황안내 페이지에 적힌 내용확인 상태
부모 또는 배우자 동의전자서명으로 동의해요. 장애 등 교육부장관과 재단이 인정하는 경우에는 오프라인으로 동의할 수 있어요공식 페이지 확인
기초·차상위 학생학생이 신청일 기준 기초·차상위이면 가구원 동의가 필요하지 않아요공식 페이지 확인
조사 소요국내 소득·재산 조사는 가구원 동의와 가족관계 서류 처리가 끝난 뒤 진행되고 약 8주가 걸려요공식 페이지 확인
거주지 정보가 조회되지 않을 때전월세는 확정일자가 포함된 임대차계약서, 주택 매수는 등기사항전부증명서, 무상거주는 재단 서식의 무료임대확인서를 제출해요공식 페이지 확인

4구간이 다르게 나왔을 때 (최신화)

항목내용확인 상태
신청 기한학자금 지원구간 통지 후 10영업일 이내에 신청할 수 있고, 기한이 지나면 신청할 수 없어요공식 페이지 확인
신청 방법상담센터(1599-2000)와 상담한 뒤 진행해요공식 페이지 확인
처리 기간신청일로부터 30일 이내 처리하나 시스템 사정으로 늦어질 수 있어요공식 페이지 확인
주의최신화 결과가 처음 구간보다 높게 나올 수 있고, 신청 이전 상태로 되돌릴 수 없다고 적혀 있어요공식 페이지 확인
이의신청 절차이의신청 메뉴 이름은 보았지만 절차 설명 본문은 읽지 못했어요미확인 · 기관 확인

5줍줍이 확인하지 못한 것

  • 한국장학재단 설립 등에 관한 법률 시행령(시행일 2025-01-31 판)에서 소득인정액이나 지원구간을 정한 조문은 찾지 못했어요
  • 구간별(0~10구간) 소득인정액 경곗값과 올해 적용 표
  • 이의신청의 요건과 절차
  • 로그인 후 내 구간을 조회하는 화면 경로

?자주 묻는 질문

지원구간은 누가 정하나요?
학생 가구의 소득·재산을 보건복지부 사회보장정보시스템으로 조사한 뒤 한국장학재단이 결정한다고 안내 페이지에 적혀 있어요.
소득인정액은 어떻게 계산하나요?
안내 페이지에는 소득평가액에 재산의 소득환산액을 더하고 형제·자매 수에 따른 공제액을 뺀다고 적혀 있어요. 세부 환산율은 줍줍이 읽지 못했어요.
부모 동의가 꼭 필요한가요?
원칙은 가구원(부모 또는 배우자)의 전자서명 동의예요. 신청일 기준 기초·차상위 학생은 가구원 동의가 필요하지 않다고 적혀 있어요.
구간이 마음에 안 들면 어떻게 하나요?
구간 통지 후 10영업일 이내에 상담센터(1599-2000)와 상담해 최신화를 신청할 수 있어요. 결과가 더 높게 나올 수 있고 되돌릴 수 없다고 안내돼 있어요.

새 공고와 마감 3일 전 · 이메일 · 가입 무료 · 언제든 끌 수 있어요
