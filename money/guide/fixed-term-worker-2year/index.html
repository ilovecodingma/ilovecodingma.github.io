12년 규칙과 예외 6가지 (제4조 제1항)

구분조문 내용확인 상태
원칙2년을 초과하지 않는 범위 안에서 기간제근로자를 사용할 수 있어요. 반복 갱신의 경우 계속 근로한 총기간이 2년을 넘지 않아야 해요조문 확인
1호사업의 완료 또는 특정한 업무의 완성에 필요한 기간을 정한 경우조문 확인
2호휴직·파견 등으로 결원이 생겨 해당 근로자가 복귀할 때까지 그 업무를 대신할 필요가 있는 경우조문 확인
3호근로자가 학업, 직업훈련 등을 이수함에 따라 그 이수에 필요한 기간을 정한 경우조문 확인
4호고령자(고용상 연령차별금지 및 고령자고용촉진에 관한 법률 제2조 제1호)와 근로계약을 체결하는 경우조문 확인
5호전문적 지식·기술의 활용이 필요한 경우와 정부의 복지정책·실업대책 등에 따라 일자리를 제공하는 경우로서 대통령령으로 정하는 경우조문 확인
6호그 밖에 1호부터 5호까지에 준하는 합리적인 사유가 있는 경우로서 대통령령으로 정하는 경우조문 확인

22년을 넘기면 어떻게 되나요 (제4조 제2항)

상황조문 내용확인 상태
예외 사유가 없거나 사라졌는데 2년 초과 사용그 기간제근로자는 기간의 정함이 없는 근로계약을 체결한 근로자로 봐요조문 확인
무기계약 근로자로 보는 시점조문에는 시점이 따로 적혀 있지 않아요. 2년 초과 시점부터인지 등 해석은 사건마다 달라요기관 확인
임금·직급 등 전환 후 근로조건제4조에는 전환 후 임금 수준이 적혀 있지 않아요기관 확인
무기계약 우선 고용 노력사용자가 기간의 정함이 없는 근로계약을 체결하려 할 때에는 해당 사업장의 동종 또는 유사한 업무에 종사하는 기간제근로자를 우선적으로 고용하도록 노력해야 해요 (제5조)조문 확인

3시행령 제3조가 정한 예외 (제4조 제1항 제5호·제6호)

시행령 조항해당하는 경우확인 상태
제3조 제1항 제1호박사 학위(외국 수여 포함)를 소지하고 해당 분야에 종사하는 경우조문 확인
제3조 제1항 제2호국가기술자격법 제9조 제1항 제1호의 기술사 등급 국가기술자격을 소지하고 해당 분야에 종사하는 경우조문 확인
제3조 제1항 제3호별표 2에서 정한 전문자격을 소지하고 해당 분야에 종사하는 경우 (자격 목록은 시행령 별표 2)별표 2 확인
제3조 제2항고용정책 기본법·고용보험법 등 다른 법령에 따라 직업능력 개발·취업 촉진·사회적으로 필요한 서비스 제공 등을 위해 일자리를 제공하는 경우, 제대군인 고용증진을 위한 경우, 국가보훈대상자 복지증진을 위해 보훈도우미 등 복지지원 인력을 운영하는 경우조문 확인
제3조 제3항 제1호다른 법령에서 기간제근로자 사용기간을 달리 정하거나 별도의 기간을 정해 근로계약을 맺을 수 있게 한 경우조문 확인
제3조 제3항 제2호·제3호국방부장관이 인정하는 군사적 전문적 지식·기술을 가진 경우나 안보·군사학 강의, 특수한 경력으로 국가안전보장·국방·외교·통일 관련 업무에 종사하는 경우조문 확인
제3조 제3항 제4호고등교육법에 따른 학교(대학원대학 포함)에서 강사·조교 업무, 또는 명예교수·겸임교원·초빙교원 등의 업무에 종사하는 경우조문 확인
제3조 제3항 제5호한국표준직업분류 대분류 1·2 직업 종사자의 최근 2년간 연평균 근로소득이 고용형태별근로실태조사 대분류 2 직업 근로소득의 상위 100분의 25에 해당하는 경우기관 확인
제3조 제3항 제6호근로기준법 제18조 제3항에 따른 1주 소정근로시간이 뚜렷하게 짧은 단시간근로자를 사용하는 경우조문 확인
제3조 제3항 제7호국민체육진흥법상 선수와 체육지도자 업무에 종사하는 경우조문 확인
제3조 제3항 제8호국공립연구기관, 정부출연연구기관, 특정연구기관, 지방자치단체출연 연구기관, 공공기관 부설 연구기관, 기업·대학 부설 연구기관, 법인인 연구기관에서 연구업무에 직접 종사하거나 연구업무를 직접 관여해 지원하는 업무에 종사하는 경우조문 확인

455세 이상 고령자 (제4조 제1항 제4호)

항목내용확인 상태
고령자의 범위기간제법 제4조 제1항 제4호는 고령자와 근로계약을 체결하는 경우를 예외로 들어요. 고령자는 고용상 연령차별금지 및 고령자고용촉진에 관한 법률 시행령 제2조 제1항에 따라 55세 이상인 사람이에요조문 확인
55세가 되는 시점조문은 고령자와 근로계약을 체결하는 경우라고 적고 있어요. 이미 2년을 넘긴 뒤 만 55세가 된 경우 등은 조문만으로 판단하지 않아요기관 확인

5계약서와 차별 금지 (제8조·제17조)

항목내용확인 상태
서면 명시 사항기간제근로자와 계약할 때 사용자는 근로계약기간, 근로시간·휴게, 임금의 구성항목·계산방법·지불방법, 휴일·휴가, 취업의 장소와 종사할 업무에 관한 사항을 서면으로 명시해야 해요 (제17조 제1호~제5호)조문 확인
근로일·근로일별 근로시간제17조 제6호는 단시간근로자에 한정해요조문 확인
차별적 처우 금지사용자는 기간제근로자임을 이유로 해당 사업장에서 동종 또는 유사한 업무에 종사하는 기간의 정함이 없는 근로계약 근로자에 비해 차별적 처우를 해서는 안 돼요 (제8조 제1항)조문 확인
차별인지 여부어떤 처우가 차별에 해당하는지는 사건별로 달라요. 줍줍은 판단하지 않아요노동청 확인

기간제로 2년 일하면 자동으로 정규직이 되나요?
제4조 제2항은 예외 사유 없이 2년을 초과해 기간제근로자로 사용하면 그 근로자를 기간의 정함이 없는 근로계약을 체결한 근로자로 본다고 해요. 정규직과 같은 임금·직급을 보장한다는 문구는 제4조에 없어요.
1년 계약을 두 번 하면 2년인가요?
제4조 제1항은 반복 갱신의 경우 계속 근로한 총기간이 2년을 넘지 않아야 한다고 적고 있어요. 중간에 공백이 있는 경우의 계산은 조문에 없어서 노동청 확인이 필요해요.
55세 이상이면 계약직으로 계속 쓸 수 있나요?
제4조 제1항 제4호가 고령자와의 근로계약을 2년 초과 사용의 예외로 들어요. 고령자는 고령자고용촉진법 시행령 제2조에서 55세 이상으로 정해요.
박사 학위가 있으면 어떻게 되나요?
시행령 제3조 제1항 제1호에 박사 학위를 소지하고 해당 분야에 종사하는 경우가 예외로 적혀 있어요. 실제 업무가 해당 분야인지는 사건마다 달라요.
계약서에 꼭 들어가야 하는 것은 무엇인가요?
제17조에 따라 근로계약기간, 근로시간·휴게, 임금 구성항목·계산방법·지불방법, 휴일·휴가, 취업 장소와 업무를 서면으로 명시해야 해요.
