걷기 운동을 처음 시작해요. 올바른 자세와 준비운동, 제자리 걷기는 공식 자료에 어떻게 적혀 있나요?

🗓 확인일 2026-10-26📎 공식 출처 4곳☎
3줄 요약
  1. 공식 안내 기준은 이렇게 적혀 있어요.
  2. 보건복지부 걷기 가이드라인 보도자료는 걷기 전후에 준비운동과 정리운동을 하고, 시작할 때 5분 정도 천천히 걷다가 속도를 높이며, 끝낼 때는 속도를 서서히 줄이라고 안내해요.
  3. 자세로는 10~15m 앞을 보고, 팔은 자연스럽게 앞뒤로 흔들며, 발은 뒤꿈치, 발바닥, 발가락 순으로 디디라고 적혀 있어요.

기준: 보건복지부 보도자료 「새로운 일상, 걷기로 시작해요!」(2020-10-26 발표), 국민건강보험공단 건강iN 4월호·5월호 걷기 기사, 질병관리청 국가건강정보포털 「운동」 페이지 · 줍줍 확인일 2026-10-26 · 원문 바로가기: 보건복지부 보도자료 「새로운 일상, 걷기로 시작해요!」 · 국민건강보험공단 건강iN 5월호 「바른 걸음걸이, 건강의 척도」 · 국민건강보험공단 건강iN 4월호 「가장 안전한 유산소 운동, 걷기」 · 질병관리청 국가건강정보포털 「운동」

⚠️ 먼저 읽어 주세요

이 글은 공식 자료의 걷기 안내를 정리한 것이고 의료 조언이 아니에요. 통증이나 지병이 있으면 공식 자료도 전문가와 먼저 상의하라고 안내하고, 줍줍은 개인별 판단을 하지 않아요.

1올바른 걷기 자세 (보건복지부 보도자료)

항목공식 안내 내용확인 상태
시선10~15m 앞을 봐요공식 자료 확인
호흡코로 자연스럽게 들이마시고 입으로 내쉬어요공식 자료 확인
상체약 5도 앞으로 기울이고 몸은 곧게 세우며 어깨와 가슴을 펴요공식 자료 확인
팔과 손팔은 자연스럽게 앞뒤로 흔들고, 주먹은 달걀을 가볍게 쥔 모양으로 해요공식 자료 확인
다리와 발 디딤다리는 일자로 걷고, 발은 뒤꿈치, 발바닥, 발가락 순으로 디뎌요공식 자료 확인
보폭자기 키(cm)-100 혹은 자기 키(cm)에 0.45를 곱한 값으로 하고 일정하게 유지해요공식 자료 확인

2국민건강보험공단 건강iN이 적은 자세와 주의

항목공식 안내 내용확인 상태
시선(5월호)눈은 아래가 아닌 정면을 보도록 해요공식 자료 확인
상체(5월호)척추와 허리를 먼저 세우고 머리를 세운 상태에서 어깨와 가슴을 펴고 걸어요공식 자료 확인
팔(5월호)팔을 앞으로 흔들기보다 뒤로 흔들어 견갑골을 움직이면 목, 어깨, 팔의 통증을 줄이는 데 도움이 될 수 있다고 해요공식 자료 확인
발 디딤(5월호)발뒤꿈치, 발바닥, 발앞꿈치(발가락) 순서로 누르듯이 걸어요. 너무 넓은 보폭은 잘못된 자세로 언급돼요공식 자료 확인
보폭과 발 방향(4월호)보폭은 키의 절반 정도가 적당하고 발 방향은 걷는 방향과 일치시켜요. 앞의 보건복지부 계산식과 수치가 달라서 기관별 안내가 서로 다르다는 점을 알아 두세요공식 자료 확인
피할 동작(4월호)뒤로 걷기와 계단 내려오기는 무릎에 큰 충격을 주므로 가능한 피해야 한다고 해요공식 자료 확인
허리 질환(5월호)허리 디스크나 요통 환자는 계단이나 가파른 언덕을 피하고, 통증을 참으며 무리하게 걷지 않아요공식 자료 확인
신발(5월호)밑창이 얇아 충격을 흡수하지 못하는 신발, 발을 꽉 조이는 신발, 발이 흔들리는 신발은 피하라고 해요. 하이힐, 통굽, 슬리퍼는 가능한 피하고 꼭 신으면 짧은 시간만 신어요공식 자료 확인

3준비운동과 정리운동

항목공식 안내 내용확인 상태
걷기 전후 (보건복지부)걷기 전후로 준비운동과 정리운동을 해요공식 자료 확인
걷기 전후 (건강iN 4월호)걷기 운동 전후에 스트레칭을 해요공식 자료 확인
운동 구성 (질병관리청)준비운동 5~10분, 본 운동 20~60분, 정리운동 5~10분으로 안내해요공식 자료 확인
준비운동 방법 (질병관리청)본 운동보다 낮은 강도로 하고 최소 5~10분 정도 관절 가동 범위 전체에 걸쳐 해요. 목적은 근육 온도를 높이고 운동할 근육으로 가는 혈액 공급을 늘려 심장과 근골격계 손상을 예방하는 것이라고 해요공식 자료 확인
정리운동 방법 (질병관리청)최소 5~10분 동안 걷기, 가벼운 조깅, 스트레칭 등 긴장을 푸는 운동을 해요. 운동 후 근육통을 줄이고 젖산 농도를 낮추는 목적이에요공식 자료 확인
걷기 자체를 준비운동으로질병관리청 이상지질혈증 안내는 준비운동을 가벼운 스트레칭 5분과 가볍게 걷기 5분으로 약 10분 구성한다고 적고 있어요공식 자료 확인
스트레칭 부위별 순서와 유지 시간보건복지부·건보공단·질병관리청 문서에서 걷기용으로 정해진 순서와 시간을 찾지 못했어요공식 확인

4처음 시작하는 사람의 속도와 시간

항목공식 안내 내용확인 상태
시작할 때 (보건복지부)처음 5분 정도는 천천히 걷다가 점차 속도를 높이고, 마칠 때는 서서히 줄여요공식 자료 확인
속도 (건강iN 4월호)걷기 속도는 천천히 시작해서 약간 빠른 정도로 걷는 것이 효과적이라고 해요공식 자료 확인
강도 구분 (질병관리청)천천히 걸으면 저강도, 속도를 높이면 중강도이고, 건강한 사람이 시속 4.5~8km로 빠르게 걷는 것이 중강도 예시로 적혀 있어요공식 자료 확인
첫 1~2주 강도와 처음 시작 시간공식기관(보건복지부·건보공단·질병관리청) 문서에서 첫 1~2주 강도와 시작 분량을 정한 문구를 찾지 못했어요공식 확인
운동 전 상담 (질병관리청)건강상 위험이 의심되면 전문가와 상의해 운동량을 정하라고 해요. 심장병 과거력, 가슴통증, 어지러움이 있거나 심한 운동을 해 본 적 없는 65세 이상, 혈압이 조절되지 않는 환자는 시작 전 전문의 상담이 좋다고 적혀 있어요공식 자료 확인

5제자리 걷기와 중단 신호

항목공식 안내 내용확인 상태
제자리 걷기 방법질병관리청 국가건강정보포털 「운동」 페이지에는 제자리 걷기 설명이 없어요. 보건복지부·건보공단 걷기 문서에서도 찾지 못했어요. 임의로 설명하지 않아요공식 확인
제자리 뛰기 관련질병관리청 안내는 심한 골다공증 환자가 제자리 뛰기나 줄넘기처럼 무릎이나 허리 관절에 충격을 주는 운동은 피하라고 해요. 이는 제자리 걷기와는 다른 동작이에요공식 자료 확인
운동 중 중단해야 하는 증상질병관리청 「운동」 페이지에 운동 중 즉시 중단할 증상 목록은 없고, 가슴통증·어지러움은 시작 전 상담 대상 설명에만 나와요. 건강iN 4월호에도 없었어요공식 확인
운동 제한 혈압 (고혈압 환자)수축기 혈압이 200mmHg를 넘거나 이완기 혈압이 115mmHg를 넘으면 운동을 금한다고 해요공식 자료 확인
허리 통증건강iN 5월호는 허리 통증을 참으며 무리하게 걷지 않으라고 해요공식 자료 확인

6참고용 안내

이 글은 보건복지부, 국민건강보험공단, 질병관리청 공개 문서를 읽고 정리한 참고용 안내이고 의료 조언이나 진단이 아니에요. 같은 항목도 기관과 발행 시점에 따라 수치가 다를 수 있어요(보폭 등). 건보공단 기사 발행일은 페이지에 표시되지 않았어요. 몸에 이상이 있거나 지병이 있으면 의료진과 상담하세요.

?자주 묻는 질문

걷기 운동을 시작할 때 처음에 어떻게 걸어야 하나요?
보건복지부 보도자료는 처음 5분 정도는 천천히 걷다가 점차 속도를 높이고, 마칠 때는 서서히 줄이라고 안내해요. 건강iN 4월호도 천천히 시작해서 약간 빠른 정도로 걷는 것이 효과적이라고 적고 있어요.
올바른 걷기 자세는 어떻게 되나요?
보건복지부 보도자료 기준으로 10~15m 앞을 보고, 몸을 곧게 세워 어깨와 가슴을 펴고, 팔은 자연스럽게 앞뒤로 흔들며, 발은 뒤꿈치, 발바닥, 발가락 순으로 디뎌요.
걷기 전에 준비운동은 얼마나 해야 하나요?
질병관리청 국가건강정보포털은 준비운동 5~10분, 정리운동 5~10분으로 안내해요. 걷기용 스트레칭 순서와 유지 시간은 공식 확인이 안 됐어요.
제자리 걷기는 공식 자료에 어떻게 나와 있나요?
이번에 읽은 질병관리청 「운동」 페이지, 보건복지부 걷기 보도자료, 건보공단 건강iN 걷기 기사에서는 제자리 걷기 방법을 찾지 못했어요. 공식 확인이 필요해서 임의로 설명하지 않아요.
걷기 중 어떤 증상이 나타나면 멈춰야 하나요?
읽은 공식 문서에는 걷기 중 즉시 중단할 증상 목록이 없었어요(공식 확인). 건강iN 5월호는 허리 통증을 참고 무리하게 걷지 말라고 하고, 질병관리청은 가슴통증이나 어지러움이 있으면 시작 전 전문의 상담을 권해요.
보폭은 얼마가 적당한가요?
기관마다 달라요. 보건복지부 보도자료는 키(cm)-100 또는 키에 0.45를 곱한 값이라고 하고, 건강iN 4월호는 키의 절반 정도라고 해요.
