홈 › 생활 돈 가이드 › 휴게시간과 근로시간 한도 (주 52시간)

휴게시간은 법으로 얼마나 줘야 하고, 일할 수 있는 시간은 주 몇 시간까지인가요?

🗓 확인일 2026-10-24📎 공식 출처 4곳☎
3줄 요약
  1. 근로기준법은 1주 근로시간을 휴게시간을 빼고 40시간, 1일 근로시간을 휴게시간을 빼고 8시간까지로 정해요(제50조 제1항·제2항). 당사자가 합의하면 1주 12시간을 한도로 이 시간을 연장할 수 있어요(제53조 제1항). 40시간에 12시간을 더한 52시간이 흔히 말하는 주 52시간이에요(조문 숫자를 더한 계산). 휴게시간은 근로시간이 4시간인 경우 30분 이상, 8시간인 경우 1시간 이상을 근로시간 도중에 줘야 하고, 근로자가 자유롭게 이용할 수 있어야 해요(제54조). 아래 표는 모두 위 조문 원문에서 확인한 내용이에요.

기준: 근로기준법 제11조·제50조~제54조·제58조·제59조·제110조, 같은 법 시행령 제7조의2·별표 1 (국가법령정보센터 법령 데이터: 법 시행 2026-10-08, 시행령 시행 2025-10-23) · 줍줍 확인일 2026-10-24 · 원문 바로가기: 근로기준법 · 근로기준법 시행령 · 국가법령정보센터 · 고용노동부

1근로시간 한도 (제50조, 제53조)

항목내용확인 상태
1주 한도1주 간의 근로시간은 휴게시간을 제외하고 40시간을 초과할 수 없어요 (제50조 제1항)조문 확인
1일 한도1일의 근로시간은 휴게시간을 제외하고 8시간을 초과할 수 없어요 (제50조 제2항)조문 확인
대기시간근로시간을 산정할 때 작업을 위해 근로자가 사용자의 지휘·감독 아래에 있는 대기시간 등은 근로시간으로 봐요 (제50조 제3항)조문 확인
연장근로 한도당사자 간에 합의하면 1주 간에 12시간을 한도로 제50조의 근로시간을 연장할 수 있어요 (제53조 제1항)조문 확인
주 52시간제50조 제1항의 40시간에 제53조 제1항의 12시간을 더한 숫자예요. 조문에 「52시간」이라는 표현이 직접 나오는 곳은 탄력적 근로시간제의 특정 주 상한(제51조 제2항, 제51조의2 제1항)이에요조문 확인 · 계산
특별한 사정특별한 사정이 있으면 고용노동부장관의 인가와 근로자의 동의를 받아 제1항·제2항의 근로시간을 연장할 수 있어요. 사태가 급박해 인가를 받을 시간이 없으면 사후에 지체 없이 승인을 받아야 해요 (제53조 제4항)조문 확인
연장근로 가산임금연장근로의 가산수당 계산은 줍줍의 연장·야간·휴일수당 가이드를 보세요다른 가이드

2휴게시간 (제54조)

항목내용확인 상태
4시간인 경우근로시간이 4시간인 경우에는 30분 이상의 휴게시간을 근로시간 도중에 줘야 해요 (제54조 제1항)조문 확인
8시간인 경우근로시간이 8시간인 경우에는 1시간 이상의 휴게시간을 근로시간 도중에 줘야 해요 (제54조 제1항)조문 확인
부여 시점조문에 휴게시간을 「근로시간 도중에」 준다고 적혀 있어요 (제54조 제1항)조문 확인
자유 이용휴게시간은 근로자가 자유롭게 이용할 수 있어요 (제54조 제2항)조문 확인
근로시간 계산과의 관계제50조의 한도는 휴게시간을 제외하고 계산해요. 한편 사용자의 지휘·감독 아래 있는 대기시간 등은 근로시간으로 봐요 (제50조 제3항)조문 확인
4시간과 8시간 사이조문에는 4시간인 경우와 8시간인 경우만 적혀 있어요. 그 사이 근로시간(예: 6시간)의 휴게시간은 고용노동부에 문의하세요기관 확인
8시간을 넘는 경우연장근로로 8시간을 넘기는 날의 휴게시간 기준은 조문에 따로 적혀 있지 않아 고용노동부에 문의하세요기관 확인

3탄력적 근로시간제와 선택적 근로시간제 (제51조·제51조의2·제52조)

제도조문 내용확인 상태
2주 이내 탄력적 근로시간제취업규칙(에 준하는 것 포함)에서 정하면 2주 이내 단위기간을 평균해 1주 근로시간이 40시간을 넘지 않는 범위에서 특정한 주에 40시간을, 특정한 날에 8시간을 초과해 근로시키게 할 수 있어요. 다만 특정한 주는 48시간을 초과할 수 없어요 (제51조 제1항)조문 확인
3개월 이내 탄력적 근로시간제근로자대표와의 서면 합의로 대상 근로자의 범위, 단위기간(3개월 이내), 단위기간의 근로일과 근로일별 근로시간 등을 정하면 가능해요. 특정한 주는 52시간, 특정한 날은 12시간을 초과할 수 없어요 (제51조 제2항)조문 확인
3개월 초과 6개월 이내근로자대표와의 서면 합의로 단위기간(3개월 초과 6개월 이내)과 주별 근로시간 등을 정하면 가능해요. 특정한 주는 52시간, 특정한 날은 12시간을 초과할 수 없고, 근로일 종료 후 다음 근로일 개시 전까지 연속 11시간 이상의 휴식을 줘야 해요 (제51조의2 제1항·제2항)조문 확인
제외 대상15세 이상 18세 미만의 근로자와 임신 중인 여성 근로자에게는 적용하지 않아요 (제51조 제3항, 제51조의2 제6항)조문 확인
임금 보전기존의 임금 수준이 낮아지지 않도록 임금보전방안을 강구해야 해요 (제51조 제4항, 제51조의2 제5항)조문 확인
선택적 근로시간제업무의 시작·종료 시각을 근로자의 결정에 맡기기로 한 근로자에 대해, 근로자대표와의 서면 합의로 정산기간(1개월, 신상품·신기술 연구개발 업무는 3개월 이내)과 정산기간의 총 근로시간 등을 정하면 정산기간 평균 1주 40시간 범위에서 1주 40시간·1일 8시간을 초과해 근로시키게 할 수 있어요 (제52조 제1항)조문 확인
정산기간이 1개월을 넘을 때연속 11시간 이상 휴식을 줘야 하고, 매 1개월마다 평균 1주 40시간을 초과한 시간에는 통상임금의 100분의 50 이상을 가산해 지급해야 해요 (제52조 제2항)조문 확인
연장근로와의 관계탄력적·선택적 근로시간제로 정한 시간도 1주 12시간 한도 안에서 연장할 수 있고, 선택적 근로시간제는 정산기간을 평균해 1주 12시간을 넘지 않는 범위예요 (제53조 제2항)조문 확인
우리 회사가 어느 제도인지취업규칙이나 서면 합의의 내용은 사업장마다 달라서 줍줍이 확인할 수 없어요기관 확인

4근로시간 계산의 특례와 특례 업종 (제58조, 제59조)

항목내용확인 상태
사업장 밖 근로출장이나 그 밖의 사유로 근로시간의 전부 또는 일부를 사업장 밖에서 근로해 근로시간을 산정하기 어려운 경우에는 소정근로시간을 근로한 것으로 봐요. 다만 그 업무 수행에 통상 소정근로시간을 초과할 필요가 있으면 업무 수행에 통상 필요한 시간을 근로한 것으로 봐요 (제58조 제1항)조문 확인
서면 합의로 정한 시간제1항 단서의 경우 근로자대표와의 서면 합의가 있으면 그 합의에서 정하는 시간을 통상 필요한 시간으로 봐요 (제58조 제2항)조문 확인
재량 위임 업무업무 수행 방법을 근로자의 재량에 위임할 필요가 있는 업무로서 대통령령으로 정하는 업무는, 사용자가 근로자대표와 서면 합의로 정한 시간을 근로한 것으로 봐요 (제58조 제3항)조문 확인
특례 업종통계법 제22조 제1항에 따라 국가데이터처장이 고시하는 산업 표준 분류 중 육상운송 및 파이프라인 운송업(노선 여객자동차운송사업은 제외), 수상운송업, 항공운송업, 기타 운송관련 서비스업, 보건업에 대해 사용자가 근로자대표와 서면으로 합의하면 주 12시간을 초과한 연장근로나 제54조의 휴게시간 변경이 가능해요 (제59조 제1항)조문 확인
특례 업종의 휴식제59조 제1항의 경우에도 근로일 종료 후 다음 근로일 개시 전까지 연속 11시간 이상의 휴식 시간을 줘야 해요 (제59조 제2항)조문 확인
재량 위임 업무의 범위대통령령으로 정하는 업무의 구체적 목록은 시행령에서 확인하세요기관 확인
내 업종의 해당 여부표준 분류상 어디에 속하는지는 사업장마다 달라서 줍줍이 판정하지 않아요기관 확인

55명 미만 사업장에도 적용되나요 (제11조, 시행령 별표 1)

항목내용확인 상태
원칙근로기준법은 상시 5명 이상의 근로자를 사용하는 모든 사업 또는 사업장에 적용돼요. 동거하는 친족만을 사용하는 사업 또는 사업장과 가사 사용인에게는 적용하지 않아요 (제11조 제1항)조문 확인
상시 4명 이하상시 4명 이하의 근로자를 사용하는 사업 또는 사업장에는 대통령령으로 정하는 바에 따라 법의 일부 규정을 적용해요 (제11조 제2항)조문 확인
제4장 근로시간과 휴식시행령 별표 1은 제4장 중 제54조, 제55조 제1항, 제63조만 4명 이하 사업장에 적용하는 규정으로 적어 두었어요. 즉 휴게시간(제54조)과 주휴일(제55조 제1항)은 별표 1에 있어요조문 확인
제50조·제53조별표 1의 제4장 칸에 제50조(1주 40시간·1일 8시간)와 제53조(연장근로 제한)는 적혀 있지 않아요조문 확인
벌칙별표 1의 제12장 칸은 제107조부터 제116조까지를, 제1장부터 제6장까지 등의 규정 중 4명 이하 사업장에 적용되는 규정을 위반한 경우로 한정한다고 적어 두었어요조문 확인
상시 근로자 수 산정법 적용 사유 발생일 전 1개월 동안 사용한 근로자의 연인원을 같은 기간 중의 가동 일수로 나눠 산정해요. 파견근로자는 연인원에서 제외하고, 기간제·단시간 근로자 등 고용형태를 불문한 모든 근로자를 포함해요 (시행령 제7조의2 제1항·제4항)조문 확인
내 사업장이 5명 이상인지일별 인원 현황에 따른 예외(시행령 제7조의2 제2항)가 있어 사업장마다 달라요. 줍줍이 판정하지 않아요기관 확인

6어기면 어떻게 되나요 (제110조)

위반 조문벌칙확인 상태
제50조 (근로시간 한도)2년 이하의 징역 또는 2천만원 이하의 벌금 (제110조 제1호)조문 확인
제53조 제1항·제2항, 같은 조 제4항 본문·제7항 (연장근로 한도 등)2년 이하의 징역 또는 2천만원 이하의 벌금 (제110조 제1호)조문 확인
제54조 (휴게)2년 이하의 징역 또는 2천만원 이하의 벌금 (제110조 제1호)조문 확인
제51조의2 제2항, 제52조 제2항 제1호, 제59조 제2항 (11시간 휴식)2년 이하의 징역 또는 2천만원 이하의 벌금 (제110조 제1호)조문 확인
제53조 제5항에 따른 명령 위반2년 이하의 징역 또는 2천만원 이하의 벌금 (제110조 제2호)조문 확인
실제 처벌 여부위반 여부와 처분은 근로감독관과 법원이 사건별로 정해요. 줍줍은 판단하지 않아요기관 확인

휴게시간은 몇 분 줘야 하나요?
근로시간이 4시간인 경우에는 30분 이상, 8시간인 경우에는 1시간 이상의 휴게시간을 근로시간 도중에 줘야 해요(근로기준법 제54조 제1항). 4시간과 8시간 사이의 근로시간에 몇 분이 필요한지는 조문에 따로 적혀 있지 않아 고용노동부 확인이 필요해요.
주 52시간은 어떻게 계산되나요?
1주 근로시간은 휴게시간을 제외하고 40시간(제50조 제1항)이고, 당사자가 합의하면 1주 12시간을 한도로 연장할 수 있어요(제53조 제1항). 40시간에 12시간을 더하면 52시간이에요.
휴게시간에 일을 시키면 어떻게 되나요?
휴게시간은 근로자가 자유롭게 이용할 수 있어야 해요(제54조 제2항). 사용자의 지휘·감독 아래 있는 대기시간 등은 근로시간으로 봐요(제50조 제3항). 특정 시간이 휴게인지 대기인지는 사건마다 달라서 고용노동부 확인이 필요해요.
5명 미만 사업장도 휴게시간을 줘야 하나요?
근로기준법 시행령 별표 1은 제4장 중 제54조(휴게), 제55조 제1항(주휴일), 제63조를 상시 4명 이하 사업장에 적용하는 규정으로 적고 있어요. 제50조와 제53조는 그 칸에 적혀 있지 않아요.
특정 주에 52시간 넘게 일할 수 있는 경우가 있나요?
탄력적 근로시간제는 단위기간을 평균해 1주 40시간을 넘지 않는 범위에서 특정한 주에 40시간을 넘겨 일하게 할 수 있어요. 2주 이내는 특정한 주 48시간, 3개월 이내와 3개월 초과 6개월 이내는 특정한 주 52시간, 특정한 날 12시간이 상한이에요(제51조, 제51조의2). 운송업·보건업 등 제59조 업종은 근로자대표와 서면 합의가 있으면 주 12시간을 넘는 연장근로가 가능하지만 11시간 연속 휴식을 줘야 해요.
근로시간이나 휴게 위반에 벌칙이 있나요?
제50조, 제53조 제1항·제2항, 제54조를 위반하면 2년 이하의 징역 또는 2천만원 이하의 벌금에 처한다고 제110조 제1호에 적혀 있어요. 실제 처벌 여부는 사건마다 달라요.
