## 2. 조치 (우선순위)
1. 신청용 색인 세트를 대표 페이지 300~500쪽으로 좁힌다: 자기개발·시험 핵심 글 + 위키 상위 가이드. 나머지는 noindex + 사이트맵 제외(페이지는 그대로 열림). 【판단】
2. 대량·틀 같은 페이지 정리: 레시피 전체 noindex(허브·상위 몇 개만), 시험 회차 상세는 시험 허브로 통합(canonical), 외국어 미러 noindex.
3. 자기개발 대표 글 30~50편을 사람 검수하며 새로 쓴다. 형식: 「무엇을·왜·어디서 무료로·얼마나 걸리나·다음 단계」, 출처와 확인일, 우리 해설 포함. 【판단】
4. 시험 정보는 일정 나열이 아니라 시험별 허브 1장에 접수 요령·준비 순서·변경점 해설을 붙인다.
5. 필수 페이지 갱신: 소개(운영자·목적·수집 방식·AI 사용 여부·갱신 주기), 문의, 개인정보처리방침, 이용약관. 이름 「가난한 박과장」 반영.
6. 자동 생성 중단: JupJup_News·연예 RSS 끔(완료). 수집 항목은 「요약 + 출처 링크 + 우리 해설」로만 게시.
7. 탐색성: 메뉴(자기개발·시험·위키·공모전·식단) 모든 페이지 동일, 깨진 링크 0, 빈 페이지 0 확인.
8. 광고: 승인 전에는 자동 광고 본문 내만, 목록·허브·에러 페이지 제외.
9. 이미지·출처 저작권 점검, 공식 로고 미사용.
