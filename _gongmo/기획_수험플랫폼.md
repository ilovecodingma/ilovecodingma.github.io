# 기획 — 수험·평생교육·자기개발 플랫폼 (2026-11-25 사용자 지시 기준)

## 1. 한 줄 정의
시험을 준비하는 사람과, 시험과 상관없이 스스로 배우는 사람이 일정·정보·연습·커뮤니티를 한곳에서 이어서 쓰는 사이트. 사이트 이름·주소는 그대로.

## 2. 두 갈래 (홈 첫 화면에서 선택)
| 갈래 | 내용 | 주소 |
|---|---|---|
| 시험 준비 | 시험 일정·접수·발표·컷·문제은행·시험 뉴스 | /exam/ /exam/bank/ /issue/ |
| 자기개발 | 시험 없이 배우는 AI·코딩·글쓰기·습관, 수업·로드맵 | /park/ /ailog/ /book/ |
곁가지: 공모전(/contest/), 식단·레시피(/diet/ /fridge/), 위키(/wiki/ — 보험·세금·지원금 등 생활 정보), 이야기방(/plaza/).

## 3. 노드로 따라가기 (이어 보기)
모든 시험·글·문제·공모전·식단을 노드로 보고, 페이지 하단에 「이어서 볼 것」을 건다.
- 시험 → 같은 분야 시험 / 앞뒤 시험(수능→정시→논술) / 관련 시험 뉴스 / 문제은행 / 도움 되는 공모전(스펙) / 시험 기간 식단 / 이야기방
- 데이터: exam_data/exam_nodes.json (from, to, kind). 없으면 같은 분류로 자동 연결.
- 기존 키워드 지도(/map/)는 시험 노드 중심으로 개편.

## 4. 커뮤니티
기존 커뮤니티(/community/, /plaza/, 원정대)를 시험별 이야기방으로 전환. 방 = 시험 id. 시험 페이지에서 곧바로 입장.

## 5. 화면
- 레퍼런스: certoday — 짙은 남색, 큰 제목+색 띠, 가운데 검색, 자주 찾는 칩.
- 공통 스킨 assets/exam-skin.css(전 페이지: 남색 헤더·푸터, 인디고 포인트, 본문은 밝게), 홈 스킨 assets/home/ct.css(남색).
- 루리: 얼굴은 유지. 수험 콘셉트 새 이미지 6종 생성 중(공부·응원·D-day·문제풀이·도시락·수상).
- 이름은 평범하게: 시험 / 시험 뉴스 / 공모전 / 식단 / 위키 / 자기개발.

## 6. 데이터 스키마
_gongmo\SCHEMA_수험.md (분류 12+자기개발, 유형별 필수 필드).

## 7. 운영(스케줄러)
소재 선정은 시험·입시·채용 중심, 연예·소문 제외(마케터 적용 완료). 공모전 수집은 학생·취준생 대상 우선(공모전 세션).

## 8. 단계
1. 홈·공통 스킨·메뉴 개편 (진행 중, 이번 배포)
2. 12분야 허브 페이지(/exam/c/<분야>/) + 시험 페이지 노드 「이어서 볼 것」
3. 자기개발 허브(배울 거리·로드맵)
4. 이야기방 시험별 전환
5. 시험 뉴스 말투 정리, 문제은행 확대(토익·임용·한능검·IT 자격)
6. 새 루리 이미지 반영, JSON-LD 적용
