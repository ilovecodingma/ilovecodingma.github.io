# 스케줄러 계획 — 자기개발 정보 수집 체계 (2026-11-25)
목표: 들어온 사람이 먹고사는 데 실제로 도움 되는 정보(자격·직무, 지원 제도·무료 교육, 재테크·세금·노동, 시사·상식, 요리·생활, IT·바이브 코딩)를 정기적으로 모아 사이트에 올린다. 수집 방식은 기존과 같고 대상만 바뀐다. 에드센스: 자동 수집물은 그대로 게시하지 않고 「요약 + 출처 + 우리 해설」을 거친다.

## 1. 흐름 (4단)
수집(스케줄러) → 선별(마케터 사이클) → 게시(publish_fast) → 빌드(매시 :05)
1) 수집: selfdev_collect.py 가 공개 출처에서 항목을 모아 selfdev_data/items.json 에 병합(중복 제거, 최근 500건). 날짜·비용은 확인된 것만, 모르면 「미확인」.
2) 선별: 마케터 정기 사이클이 items.json 에서 하루 3~5건을 골라 우리 해설(누구에게 필요한가·언제까지·어디서·다음 단계)을 붙인 글로 만든다. 사람/세션 검수 후 게시.
3) 게시: 글 + 시험·자격 항목은 exam_articles.json/스키마 필드로 등록. 사이트 허브(자기개발·시험)에 자동 노출.
4) 빌드: GongmoWangBuild(매시 :05).

## 3. 출처 기준
- 공공기관·정부·평생학습 포털 우선, 로그인·API 키 없는 공개 페이지만. 요청 간격 1초 이상, 원문 장문 복사 금지, 연예·소문·광고성 제외.

## 4. 단계
1. 수집기 완성·시험 실행 (에이전트 작업 중)
2. SelfDev_Collect 작업 스케줄러 등록(주기 확정 후)
3. 마케터 선별·해설 사이클을 items.json 기준으로 전환(지시 전달)
4. 자기개발 허브 페이지가 items.json 을 읽어 「오늘 뭐하지」 목록으로 노출(개발)
5. 2주 뒤 출처별 건수·클릭을 점검해 출처 교체

## 5. 확인 필요
- JupJup_News 가 만드는 글을 게시 전에 누가 검수하나(마케터 사이클로 일원화 권장).
