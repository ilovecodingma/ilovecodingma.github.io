# 연말정산 공제 한도 총정리 (2026년 귀속): 소득공제·세액공제 항목별 한도와 조문

확인일: 2026-10-30

안녕하세요, 루리의 줍줍이에요. 2026년 귀속 연말정산(2027년 초 정산)에서 많이 쓰는 공제 항목의 한도를 소득세법과 조세특례제한법 조문에서 직접 확인해 표로 모았어요. 기준은 국가법령정보센터의 현행 조문(소득세법 시행 2026.7.1., 조세특례제한법 시행 2026.9.18.)이에요. 개정 이력이 있는 항목은 표에 개정일을 같이 적었고, 2026년 귀속 적용 여부를 부칙까지 확인하지 못한 부분은 맨 아래에 적었어요.

## 1. 소득공제 (과세표준에서 빼는 금액)
| 항목 | 한도·공제액 | 조문 |
|---|---|---|
| 근로소득공제 | 총급여액 구간별 금액을 공제하되 공제액이 2천만원을 넘으면 2천만원까지만 | 소득세법 제47조 제1항 |
| 기본공제 | 본인·배우자·부양가족 1명당 연 150만원 (부양가족 소득금액 합계 100만원 이하, 총급여 500만원 이하 근로소득만 있으면 포함) | 소득세법 제50조 제1항 |
| 추가공제: 경로우대 | 70세 이상 1명당 연 100만원 | 제51조 제1항 제1호 |
| 추가공제: 장애인 | 1명당 연 200만원 | 같은 항 제2호 |
| 추가공제: 부녀자 | 종합소득금액 3천만원 이하, 배우자 없는 여성 세대주(부양가족 있음) 또는 배우자 있는 여성 연 50만원 | 같은 항 제3호 |
| 추가공제: 한부모 | 배우자 없고 기본공제 대상 직계비속·입양자 있으면 연 100만원 (부녀자 공제와 겹치면 한부모 공제 적용) | 같은 항 제6호 |
| 연금보험료공제 | 그 과세기간에 낸 공적연금 연금보험료(기여금·개인부담금) 전액 | 제51조의3 제1항 |
| 건강·고용·노인장기요양보험료 | 근로자가 부담하는 보험료 지급액 | 제52조 제1항 |
| 주택임차차입금 원리금 상환액 | 상환액의 40%. 이 공제와 주택청약종합저축 공제를 합해 연 400만원 한도 | 제52조 제4항 |
| 장기주택저당차입금 이자상환액 | 기본 연 800만원 한도. 상환기간 15년 이상 고정금리+비거치식 분할상환 2천만원, 15년 이상 고정금리 또는 비거치식 1천800만원, 10년 이상 고정금리 또는 비거치식 600만원 | 제52조 제5항·제6항 |
| 주택청약종합저축 | 총급여 7천만원 이하 무주택 세대주 등이 납입한 금액(연 300만원 한도)의 40% | 조세특례제한법 제87조 제2항 |
근거: 국가법령정보센터 소득세법(시행 2026.7.1., 법률 제21221호) https://www.law.go.kr/법령/소득세법 , 조세특례제한법(시행 2026.9.18., 법률 제21467호) https://www.law.go.kr/법령/조세특례제한법 (확인일 2026-10-30)

## 2. 신용카드 등 사용금액 소득공제 (조세특례제한법 제126조의2, 2028.12.31.까지 사용분)
| 항목 | 내용 |
|---|---|
| 공제 문턱 | 연간 사용액이 총급여액의 25%를 넘는 부분부터 계산 |
| 공제율 | 전통시장 40%, 대중교통 40%, 문화체육(도서·신문·공연·박물관·미술관·영화관·체육시설) 30%(총급여 7천만원 이하), 직불·선불카드·현금영수증 30%, 신용카드 15% |
| 기본 한도 | 연 250만원. 총급여 7천만원 이하는 연 300만원 |
| 자녀 등이 있을 때 한도 | 총급여 7천만원 이하: 자녀등 1명 연 350만원, 2명 이상 연 400만원. 총급여 7천만원 초과: 1명 연 275만원, 2명 이상 연 300만원 |
| 한도 초과 시 추가 공제 | 전통시장·대중교통 사용분 합계 연 200만원 한도(총급여 7천만원 이하는 문화체육 사용분을 더해 연 300만원 한도). 2024년 증가분 공제는 2024년 과세연도 한정 |
| 제외 | 사업소득 관련 비용, 자동차 구입 등 |
근거: 조세특례제한법 제126조의2 제1항~제4항, 제10항·제11항 (2025.12.23. 개정 반영, 확인일 2026-10-30)

## 3. 세액공제 (산출세액에서 직접 빼는 금액)
| 항목 | 공제율·금액 | 한도 | 조문 |
|---|---|---|---|
| 근로소득세액공제 | 근로소득 산출세액에 대해 계산 | 총급여 3,300만원 이하 74만원. 3,300만원 초과 7천만원 이하 74만원-(총급여-3,300만원)×8/1000 (최소 66만원). 7천만원 초과 1억2천만원 이하 66만원-(총급여-7천만원)×1/2 (최소 50만원). 1억2천만원 초과 50만원-(총급여-1억2천만원)×1/2 (최소 20만원) | 소득세법 제59조 제2항 |
| 자녀세액공제 | 기본공제 대상 자녀 및 손자녀로서 13세 이상인 사람 1명 25만원, 2명 55만원, 3명 이상 55만원+2명 초과 1명당 40만원 | 같음 | 제59조의2 제1항 |
| 출산·입양 세액공제 | 해당 연도 출산·입양 신고: 첫째 30만원, 둘째 50만원, 셋째 이상 70만원 | 같음 | 제59조의2 제3항 |
| 연금계좌세액공제 | 납입액의 12% (종합소득금액 4,500만원 이하, 근로소득만 있으면 총급여 5,500만원 이하는 15%) | 연금저축 연 600만원, 연금저축(600만원 이내)+퇴직연금계좌 합계 연 900만원 | 제59조의3 제1항 |
| 보험료 세액공제 | 일반 보장성보험 12%, 장애인전용 보장성보험 15% | 각각 연 100만원 | 제59조의4 제1항 |
| 의료비 세액공제 | 15% (미숙아·선천성이상아 20%, 난임시술 30%). 총급여의 3%를 넘는 지출분 | 일반 의료비(제1호) 연 700만원. 본인·6세 이하·65세 이상·장애인·중증질환자 등(제2호), 미숙아(제3호), 난임시술(제4호)은 조문에 연 한도 문구 없음 | 제59조의4 제2항 |
| 교육비 세액공제 | 15% | 기본공제 대상 직계비속·배우자·형제자매 등: 대학생 1명 연 900만원, 취학 전 아동·초중고 1명 연 300만원 (대학원 제외). 본인 교육비는 조문에 연 한도 문구 없음 | 제59조의4 제3항 |
| 기부금 세액공제 | 15% (공제 대상 기부금 1천만원 초과분 30%) | 공제 대상은 특례기부금과 일반기부금. 일반기부금 한도: 종교단체 기부가 있으면 소득금액×10%+(소득금액×20%와 종교단체 외 기부금 중 적은 금액), 그 외 소득금액×30% | 제59조의4 제4항 |
| 고향사랑 기부금 세액공제 | 10만원 이하 110분의 100, 10만원 초과 20만원 이하 구간 40%, 20만원 초과 2천만원 이하 구간 15% (특별재난지역 기부 30%) | 개인별 연간 기부 상한 2천만원 | 조세특례제한법 제58조 제1항, 고향사랑기부금법 제8조 제3항 |
| 월세 세액공제 | 총급여 8천만원 이하(종합소득금액 7천만원 초과자 제외) 월세액의 15%. 총급여 5,500만원 이하(종합소득금액 4,500만원 초과자 제외)는 17% | 월세액 연 1천만원까지. 세대주의 배우자가 요건을 갖추면 추가 적용 가능하되 부부 월세 합계 1천만원 한도 (2025.12.23. 신설) | 조세특례제한법 제95조의2 제1항·제2항 |
| 표준세액공제 | 위 특별소득공제·특별세액공제·월세 공제 신청을 하지 않은 근로자 연 13만원 | 같음 | 소득세법 제59조의4 제9항 제1호 |
근거: 소득세법·조세특례제한법·고향사랑기부금에 관한 법률(시행 2025.1.1.) 위 URL (확인일 2026-10-30)

## 4. 월세 세액공제 주택 요건 (조세특례제한법 시행령 제95조 제2항, 2026.2.27. 개정 반영)
| 항목 | 내용 |
|---|---|
| 주택 규모·가격 | 국민주택규모 주택 또는 기준시가 4억원 이하. 기본공제 대상 자녀·손자녀가 3명 이상이면 주거전용면적 100제곱미터 이하이거나 기준시가 4억원 이하 |
| 대상 주택 | 오피스텔·고시원업 시설 포함 |
| 주소 요건 | 임대차계약증서 주소지와 주민등록표 등본 주소지가 같을 것 |
| 계약 당사자 | 본인 또는 기본공제 대상자가 임대차계약을 체결할 것 |
근거: 국가법령정보센터 조세특례제한법 시행령(시행 2026.9.18.) https://www.law.go.kr/법령/조세특례제한법시행령 (확인일 2026-10-30)

## 5. 날짜 기준
| 항목 | 내용 | 조문 |
|---|---|---|
| 공제 대상 판정 기준일 | 배우자·부양가족·장애인·경로우대자 해당 여부는 과세기간 종료일(12월 31일) 현재 상황. 사망·장애 치유는 사망일·치유일 전날 기준 | 소득세법 제53조 제4항 |
| 나이 요건 | 부양가족 나이는 과세기간 중 해당 나이에 해당되는 날이 있으면 공제 대상 | 제53조 제5항 |
| 지출 시점 | 해당 과세기간(1월 1일~12월 31일)에 지급한 금액이 공제 대상 | 제59조의4 각 항 |

## 확인 못 한 부분
- 근로소득공제 총급여 구간별 공제액 표: 확인 못 함 (국가법령정보센터 조문 화면의 표를 이 글 작성 과정에서 추출하지 못함. 한도 2천만원만 확인)
- 2026년 귀속 연말정산 간소화 서비스 개통일과 국세청 연말정산 안내 공고: 확인 못 함 (2026-10-30 현재 미공고)
- 2025.12.23. 개정 조문(신용카드 한도, 월세 배우자 추가 공제 등)의 2026년 귀속 적용 시기: 확인 못 함 (부칙 적용례 미확인)
- 자녀세액공제 「13세 이상」 연령 요건의 개정 경위와 적용 시기: 확인 못 함 (조문 표기만 확인)
- 의료비·교육비 시행령상 세부 대상 범위: 확인 못 함
