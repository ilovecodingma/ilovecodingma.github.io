책의 구성 — 『가난한 박과장과 퇴근후 나의 서비스팀 관리하기』

책은 하네스의 참고서입니다. 하네스에서 지나간 일이 개발 전체의 어디이고, 그 밑에서 무엇이 움직였는지를 흐름으로 설명합니다. 부 이름은 첫 화면의 개발의 흐름(만들기, 올리기, 운영하기, 확장하기)과 같습니다. 처음부터 읽지 않아도 되고, 하네스로 만들다 궁금해진 자리에서 해당 절을 찾아 읽으면 됩니다.

제1부 만들기

하네스로 한 줄을 넣어 첫 결과물을 만들고, 고치고, 확인하는 흐름입니다.

전체 그림

  • 개발 흐름 개요
  • 실습 사이트의 구조

글 사이트 만들기

  • 개발 환경 구성
  • 정적 사이트 생성과 로컬 실행
  • 요구사항 정의
  • 에이전트와 모델의 동작 구조
  • 구현, 검증, 롤백
  • 검증의 단계
  • 디버깅 절차
  • 하네스 개발 중의 문제 사례 10가지
  • 작업 재개와 상태 저장

쇼핑몰(가게) 만들기

  • 서버가 필요해지는 시점
  • 쇼핑몰 실행과 구조
  • 데이터 구조와 데이터베이스
  • 이미지와 영상 처리
  • 기능 모듈 켜기와 끄기
  • 서비스 방향 전환(피벗)
  • 결제 정보와 개인정보 관리

에이전트 지시와 승인

  • 짧은 지시가 넓게 실행된 사례
  • 한 글자 승인의 범위
  • 질문과 대기의 기준
  • 하네스의 설계 원리
  • 지침 파일과 규칙의 위치
  • 권한과 차단 규칙

운영체제와 실행 환경

  • 운영체제와 메모리
  • 문자 인코딩, 경로, 줄바꿈
  • 동시 처리와 잠금
  • 요청, 쿠키, 로그인
  • 라이브러리와 버전
  • 기기와 브라우저
  • 모델의 문맥과 사용량 한도
  • 권한과 비밀 값

제2부 올리기

만든 것을 인터넷 주소로 열고, 검색과 방문까지 이어지는 흐름입니다.

배포와 네트워크

  • 배포와 주소
  • 공개의 네 단계: 로컬, 공개, 검색, 방문
  • 네트워크
  • 호스팅과 외부 서비스
  • 단일 장애점과 서버 이전

공개 이후: 검색, 앱, 보안

  • 검색 엔진의 수집과 색인
  • 앱 패키지와 배포
  • 공개 서비스의 보안
  • 프롬프트 인젝션
  • 브라우저 자동화
  • 입금, 결제, 정산
  • 서비스 공개 전 점검

  • 보조 에이전트 활용

저자의 팀

  • 저자의 정보 사이트 개요
  • 저자의 팀 구성 변천
  • 사례 검색, 운영 기록, 이야기방

  • 장애 대응 절차

  • 변경 관리

  • 세션 간 메시지 전달
