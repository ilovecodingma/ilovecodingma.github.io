AI 에이전트가 공식 자료를 보고 새로 만들었고, 다른 AI 에이전트가 검수했어.

파이썬 프로그래밍 개념 정리

파이썬 입문 과목은 변수·자료형, 리스트와 딕셔너리, 조건·반복, 함수를 다룬다. 시험에서는 짧은 코드를 읽고 출력 결과를 맞히는 문제가 가장 중요하다.

1. 변수와 자료형, 연산자

변수는 값에 붙이는 이름표다. 파이썬은 자료형을 미리 적지 않고 x = 7 처럼 이름표만 붙이면 된다. 자주 나오는 자료형은 정수(int), 실수(float), 문자열(str), 참거짓(bool)이다. x = 7 y = 2 print(x / y, x // y, x % y, x ** y) 출력은 3.5 3 1 49 이다. /는 항상 실수 나눗셈이라 3.5, //는 몫만 남겨 3, %는 나머지라 1, **는 거듭제곱이라 7의 2제곱인 49가 나온다. 시험에서는 / 와 // 의 차이, 그리고 int("3") 처럼 자료형을 바꾸는 형변환이 단골이다. 문자열 "3" + "4" 는 "34" 로 이어 붙고, 숫자 3 + 4 는 7 이 된다는 점도 함께 기억한다.

  • / 는 실수 나눗셈, // 는 몫, % 는 나머지
  • 자료형은 값이 정하고, 변수는 이름표일 뿐이다
  • 문자열 + 는 이어 붙이기
2. 리스트와 인덱싱·슬라이싱

리스트는 여러 값을 순서대로 담는 상자 줄이다. 번호(인덱스)는 0부터 시작하고, 뒤에서부터는 -1, -2로 센다. a = [3, 1, 2] a.append(5) print(a[0], a[-1], a[1:3], len(a)) a 는 append 로 끝에 5가 붙어 [3, 1, 2, 5] 가 된다. 그래서 a[0] 은 3, a[-1] 은 5 이다. a[1:3] 은 1번부터 3번 직전까지 자르므로 [1, 2] 이고, len(a) 는 길이 4 이다. 슬라이싱 a[시작:끝] 은 끝 번호가 포함되지 않는다는 점이 가장 많이 틀리는 부분이다. 문자열도 같은 방식이라 "hello"[1:3] 은 "el" 이고, [::-1] 은 거꾸로 뒤집는다.

  • 인덱스는 0부터, 음수는 뒤에서부터
  • 슬라이싱의 끝 번호는 포함되지 않는다
  • append 는 끝에 추가
3. 조건문과 반복문

if 는 조건이 참일 때만 들여쓴 줄을 실행하고, for 는 정해진 횟수나 목록만큼 되풀이한다. 파이썬은 중괄호 대신 들여쓰기로 범위를 나눈다. total = 0 for i in range(1, 5): if i % 2 == 0: continue total += i print(total) range(1, 5) 는 1, 2, 3, 4 를 만든다(5는 빠진다). i가 짝수이면 continue 로 아래 줄을 건너뛰고 다음 바퀴로 간다. 그래서 홀수 1과 3만 더해져 출력은 4 이다. break 는 반복을 아예 끝내고, continue 는 이번 바퀴만 건너뛴다. while 은 조건이 참인 동안 계속 돌아서 조건을 바꾸지 않으면 무한 반복이 된다.

  • range(1,5) 는 5를 포함하지 않는다
  • continue 는 건너뛰기, break 는 종료
  • 들여쓰기가 곧 문법이다
4. 함수와 재귀

함수는 자주 쓰는 일을 묶어 이름을 붙인 것이다. def 로 만들고 return 으로 결과를 돌려준다. 재귀는 함수가 자기 자신을 다시 부르는 방식이고, 반드시 멈추는 조건(기저 조건)이 있어야 한다. def fact(n): if n <= 1: return 1 return n * fact(n - 1) print(fact(4)) fact(4) 는 4 * fact(3) 을 계산하려 fact(3) 을 부르고, 이렇게 fact(1) 까지 내려간다. fact(1) 이 1 을 돌려주면 위로 올라오며 2*1, 3*2, 4*6 으로 곱해져 24 가 출력된다. 기저 조건 n <= 1 을 빼먹으면 끝없이 자신을 불러 오류가 난다. 매개변수는 함수가 받는 값, 인자는 부를 때 넘기는 값이라는 용어 구분도 시험에 나온다.

  • return 이 함수의 결과값이다
  • 재귀에는 기저 조건이 꼭 필요하다
  • fact(4) 의 결과는 24
5. 딕셔너리와 튜플·집합

딕셔너리는 이름(키)으로 값을 찾는 사전이다. 학생 번호로 이름을 찾듯이 키와 값을 짝지어 둔다. d = {"a": 1, "b": 2} d["c"] = 3 for k, v in d.items(): print(k, v) 처음에는 키 a, b 만 있다가 d["c"] = 3 으로 새 짝이 들어가 3개가 된다. items() 는 (키, 값) 짝을 하나씩 내주므로 a 1, b 2, c 3 이 한 줄씩 출력된다. 튜플은 한 번 만들면 바꿀 수 없는 리스트로 (1, 2) 처럼 소괄호를 쓴다. 집합은 중복 없이 값만 모아 두는 상자이며 {1, 2, 2} 는 {1, 2} 가 된다. 딕셔너리의 키는 바뀌지 않는 값만 쓸 수 있다.

  • 딕셔너리는 키로 값을 찾는다
  • 튜플은 바꿀 수 없고 집합은 중복이 없다
  • items() 는 키와 값을 함께 준다
6. 변수 공유(참조)와 복사

리스트를 다른 변수에 대입하면 복사본이 생기지 않고 같은 리스트에 이름표가 하나 더 붙는다. 비유하면 한 집에 문패가 두 개 붙은 셈이다. a = [3, 1, 2, 5] b = a b.append(9) print(a) b 로 9를 추가했지만 같은 리스트이므로 a 를 찍어도 [3, 1, 2, 5, 9] 가 나온다. 진짜 복사본이 필요하면 b = a.copy() 나 b = a[:] 를 쓴다. 숫자나 문자열은 바꿀 수 없는 값이라 이런 문제가 생기지 않는다. 이 차이를 묻는 결과 예측 문제가 자주 출제된다. 함수에 리스트를 넘겨 안에서 append 하면 밖의 리스트도 바뀌는 것도 같은 원리이다. 반대로 함수 안에서 x = x + 1 처럼 숫자를 다시 대입하면 밖의 값은 그대로이다.

  • 대입은 복사가 아니라 이름표 추가
  • 복사는 copy() 또는 [:]
  • 리스트는 바뀌는 값, 문자열은 안 바뀐다
7. 예외 처리와 문자열 다루기

예외는 실행 중 생기는 오류이다. try 안에서 오류가 나면 해당 except 로 건너뛰어 프로그램이 죽지 않게 한다. try: int("abc") except ValueError: print("오류") finally: print("끝") "abc" 는 숫자로 바꿀 수 없어 ValueError 가 나고, except 가 받아 오류를 출력한다. finally 는 오류가 있든 없든 마지막에 항상 실행되어 끝이 이어서 나온다. 문자열은 s.upper() 로 대문자 변환, s.split() 으로 쪼개기, s.replace("a","b") 로 바꾸기를 쓴다. f"{x}번" 처럼 f 문자열을 쓰면 값을 문장 안에 바로 끼워 넣을 수 있다.

  • try 에서 오류가 나면 except 로 간다
  • finally 는 항상 실행된다
  • f 문자열로 값을 문장에 끼운다
8. 리스트 컴프리헨션과 내장 함수

컴프리헨션은 반복문으로 리스트를 만드는 과정을 한 줄로 쓴 것이다. 읽는 순서는 오른쪽에서 왼쪽으로, 먼저 어떤 숫자를 돌고, 조건에 맞으면, 앞의 식으로 만든다고 보면 쉽다. print([n * n for n in range(5) if n % 2 == 0]) range(5) 는 0~4 이다. 이 중 짝수인 0, 2, 4 만 통과해 제곱하므로 [0, 4, 16] 이 출력된다. 자주 쓰는 내장 함수는 len(길이), sum(합), max·min(최대·최소), sorted(정렬된 새 리스트), range, enumerate(번호와 값을 함께) 이다. sorted 는 원본을 바꾸지 않고 새 리스트를 돌려주고, a.sort() 는 원본 자체를 바꾼다.

  • 컴프리헨션: 식 for 변수 in 범위 if 조건
  • sorted 는 새 리스트, sort 는 원본 변경
  • range(n) 은 0 부터 n-1 까지
한 장 요약
  • / 는 실수 나눗셈, // 는 몫, % 는 나머지, ** 는 거듭제곱
  • 인덱스는 0부터, 슬라이싱 끝 번호는 포함되지 않는다
  • range(a, b) 는 b 를 포함하지 않는다
  • break 는 반복 종료, continue 는 이번 바퀴 건너뛰기
  • 재귀 함수에는 멈추는 기저 조건이 필요하다
  • 리스트 대입은 복사가 아니라 같은 대상을 가리킨다
  • 딕셔너리는 키로 값을 찾고, 튜플은 바꿀 수 없다
  • try-except-finally 에서 finally 는 항상 실행된다
  • 컴프리헨션: [식 for 변수 in 범위 if 조건]
