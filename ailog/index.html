🧩 구조: 매시간 이렇게 돌아가요

  1. ① 수집 (내 PC, 매시간)공모전·지원금 정리 → 언론사 RSS 15곳+연예 8곳 → 커뮤니티 인기글 → 증권·코인 기사 → 구글 트렌드
  2. ② 가공 (파이썬)같은 사건 묶기, 기사 채점, 애널리스트 발언 노드 분석, 키워드 상세, 매거진 한 호
  3. ③ 빌드 (파이썬 → HTML)페이지 3천여 개를 정적 HTML로 만들고 사이트맵까지 생성
  4. ④ 배포 (git push)GitHub Pages가 자동 공개, 몇 분 안에 반영
  5. ⑤ 동적 기능 (Cloudflare)로그인·찜·원정대·준비 보드·꿀팁·방문자 집계·폰 알림 구독·사진 인식

💬 사람이 한 말 → AI가 만든 것

실제 지시를 그대로 옮겼어요. 사람은 방향만 말하고, 코드·디자인·배포·검사는 AI가 했어요.

  • 🙋 관리자 계정 만들고 볼수 있게해

    🤖 방문 기록을 직접 집계하는 서버(봇 걸러내기·IP는 하루 단위로만 섞어 저장)와 관리자 화면: 오늘·30분·14일 막대·유입·지역·페이지

  • 🙋 사진찍으면 분류되는 거 없나ㅜ 모델로

    🤖 무료 공개 비전 모델로 냉장고 사진 속 재료를 자동 체크. 비용이 안 나가게 하루 사용량을 막아 둠

  • 🙋 앱도 사이트내 배포 하나하고

    🤖 스토어 없이 홈 화면에 설치되는 웹앱 + 관심 분야 새 공모전·마감 임박 폰 알림

  • 🙋 RSS 피드로 나오는 뉴스들 중 … 팩트체크로

    🤖 언론사 15곳 기사를 같은 사건끼리 묶고, 교차 보도·출처·제목-본문 일치·숫자 엇갈림·낚시 표현으로 기사마다 점수

  • 🙋 사고는 빼고 정치 관련해서 위주로

    🤖 사고·사망 이슈는 순위에서 빼고, 정치 이슈는 발언·주장 표시와 언론사별 제목 비교

  • 🙋 애널리스트들의 발언을 따라 노드를 나눠서 분석

    🤖 증권사 리포트 기사 1건 = 노드 1개(증권사·방향·목표가·근거). 종목마다 상승·하락 근거 트리, 코인은 강세·약세 + 30일 차트

  • 🙋 공모전 20, 애널리스트 분석 40, 이슈 40

    🤖 홈 첫 화면과 상단 탭 순서를 비중대로 재배치

  • 🙋 루리 풍자도 메인에 올리고 매일매일 하나씩

    🤖 그날 만평이 폴더에 들어오면 매시 빌드가 홈 맨 위에 올리고 날짜별로 쌓음

  • 🙋 메인이 너무 난잡… 테마를 정하고 테마별 맞춤 UI, AI 로그 등 분리

    🤖 메인은 테마 입구 4개만 남기고, 이슈·머니·공모전·생활·AI 로그를 색·메뉴가 다른 독립 화면으로 분리. 들어온 경로(지식인·SNS·개발 커뮤니티)에 맞는 입구를 맨 위로

  • 🙋 챗봇도 최적화 시키고

    🤖 테마마다 다른 루리 챗봇: 이슈는 탐정 루리, 머니는 증권사·전문가 의견, 생활은 지원금·청약·오늘 메뉴. 데이터는 열 때만 불러와 가볍게

  • 🙋 청약 추천도 만들어

    🤖 지역·나이·결혼·자녀·무주택 기간 등을 고르면 청약 가점(84점), 노려볼 공급 유형, 지금 접수 중인 공고를 골라 줌

  • 🙋 주식 관련해서도 정책, 나이별 포트폴리오, 전문가 이야기

    🤖 공식 자료로 확인한 투자 정책 표(ISA·연금저축·청년미래적금·세제·공매도), 나이별 일반 원칙, 실명 전문가 발언을 주제별로 모아 엇갈리면 나란히 비교

  • 🙋 자연유입이 되게 전략을 짜봐

    🤖 RSS 피드, 내용이 바뀐 날만 찍는 사이트맵, 얇은 페이지 검색 제외, 자바스크립트 화면을 글자로 미리 그리기, 검색어 모양 제목

🛠️ AI가 틀린 것과 고친 것

  • ❌ 요리하는 루리 그림 손이 셋처럼 보임✅ 사용자: 「아수라냐 손 꼬라지가」 → 손이 어색한 포즈는 전부 빼고, 손을 확인한 그림만 다시 씀
  • ❌ 옛날 기사(1년 전)가 오늘 증권 리포트로 들어감✅ 기사 날짜를 RSS → 주소 → 기사 정보 순으로 확인하고, 모르거나 7일 넘으면 버리게 고침
  • ❌ 서로 다른 사건이 한 이슈로 묶임✅ 기사끼리 사슬처럼 이어 묶던 방식을, 첫 기사 기준으로만 묶게 바꿈
  • ❌ 강조용 작은따옴표를 인용문으로 착각해 감점✅ 큰따옴표 인용만 본문과 비교하게 고침
  • ❌ 냉장고 1등 메뉴 카드가 세로로 깨짐✅ 사이트 공용 디자인 이름과 겹친 걸 찾아 이름을 바꿈
  • ❌ 폰에서 화면이 옆으로 밀림✅ 긴 제목이 칸을 밀어내던 목록에 줄바꿈·폭 제한을 걸어 고침
  • ❌ 방문자 집계에 미국 서버 12명이 섞임✅ 링크 없이 해외에서 들어온 자동 점검 프로그램은 빼고, 첫 유입 경로를 사람이 읽는 채널 이름으로 묶음
  • ❌ 키워드에 「:」가 들어가면 페이지가 안 만들어짐✅ 주소를 한글·영문·숫자만으로 만들도록 바꿈

📏 지킨 원칙

  • robots.txt 로 수집을 막은 곳(포털 금융·컨센서스 등)은 쓰지 않아요
  • 기사 본문은 분석에만 쓰고 옮겨 싣지 않아요 — 제목·링크·판정만
  • 주가·코인은 남의 전망을 정리할 뿐, 직접 예측하거나 매수를 권하지 않아요
  • 기사 점수는 확인 신호이지 사실 최종 판정이 아니라고 늘 적어요
  • 개인 신상·사생활·혐오·비방 글은 모으지 않아요
