드래곤포니 싱글 Calling back 발매, 안태규 권세혁 고강훈 3인 첫 컴백 정리

  • 텐아시아는 12월 5~6일 서울 블루스퀘어에서 단독 콘서트가 열린다고 전했습니다.
  • 확인일은 2026-11-10입니다.

1. 결론: 3인 체제 첫 싱글 Calling back 11월 5일 발매

안테나는 10월 13일 드래곤포니의 싱글 Calling back 발매 일정을 발표했고, 음반은 11월 5일 오후 6시 공개됐습니다. 텐아시아와 MK스포츠는 3월 EP RUN RUN RUN 이후 약 8개월 만의 컴백이라고 보도했습니다. 멤버는 안태규, 권세혁, 고강훈 3인입니다.

5. 소속사 발표와 멤버 인터뷰

  • 안테나는 10월 13일 "드래곤포니는 자신들만의 이야기와 감정을 솔직하게 풀어내며 팀의 음악적 정체성을 더욱 굳건히 할 예정"이라고 밝혔습니다. (텐아시아)
  • 안태규는 TV서울 인터뷰에서 "걱정도 많았지만 이럴 때일수록 가장 좋은 음악을 들려드리는 것이 최선이라고 생각했어요"라고 말했습니다.
  • 고강훈은 "이전보다 드래곤포니의 음악이 더 성숙해졌다는 이야기를 듣고 싶다"고 말했습니다. (TV서울)
  • 텐아시아는 신보 작업 중 오후 1시부터 7시까지 함께 작업하는 시간을 정했고, 곡 크레딧을 드래곤포니로 통일하기로 했다고 전했습니다.
  • 뉴스1은 권세혁이 "음악으로 진심 전할 것"이라는 취지로 말했다고 보도했습니다.
