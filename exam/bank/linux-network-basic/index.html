리눅스·네트워크 기초 문제은행 AI가 기출을 분석해 개편한 문제

출처: 제9회 리눅스마스터 1급 1차 문제지(KLDP 게시) / Linux man-pages / IETF RFC · 이용 조건: 기출을 분석해 문항을 새로 개편, 사실 확인은 공식 자료 참고

AI 개편 문제 · 기출을 분석해서 AI가 다시 개편했어. 처음부터 만든 거 아니야.

해당 모든 문제는 멀티 에이전트(AI)들이 기출문제를 서치해 분석한 뒤 다시 개편한 문제야. 처음부터 만든 게 아니고, 실제 시험이랑 달라. 법령은 시험 전에 다시 확인해.

1.다음 중 시스템을 다시 시작하는 것이 아니라 종료(halt/poweroff)하는 명령은?

  1. reboot
  2. init 6
  3. init 0
  4. shutdown -r now
정답과 해설

정답 3번. init 6, reboot, shutdown -r now 는 재부팅이고 init 0 은 런레벨 0(종료)으로 전환한다. 근거 보기

  1. RPM 형식의 패키지이며 64비트(x86_64) 아키텍처용이다
  2. deb 형식의 32비트 전용 패키지다

9.리눅스 파일시스템 계층 구조에서 시스템 전반의 설정 파일이 놓이는 디렉터리는?

11.chmod 754 file 을 실행했을 때 파일의 권한 표시(rwx)는?

  1. rwxr-xr-x
  2. rwxrw-r--
  3. rwxr-xr--
  4. rw-r-xr--
정답과 해설

정답 3번. 각 자리는 r=4, w=2, x=1의 합이다. 7=rwx(소유자), 5=r-x(그룹), 4=r--(기타)이므로 rwxr-xr--다. 근거 보기

12.umask가 022일 때 새로 만든 일반 파일과 디렉터리의 기본 권한은? (파일 기본 666, 디렉터리 기본 777 기준)

  1. 파일 644, 디렉터리 755
  2. 파일 755, 디렉터리 644
  3. 파일 666, 디렉터리 777
  4. 파일 600, 디렉터리 700
정답과 해설

정답 1번. 결과 권한은 기본 모드 & ~umask다. 666 & ~022 = 644, 777 & ~022 = 755이다. 파이썬 비트 연산으로 확인했다. 근거 보기

13.ln 명령에 대한 설명으로 옳은 것은?

  1. -s 옵션을 주면 하드 링크를, 주지 않으면 심볼릭 링크를 만든다
  2. 옵션과 관계없이 항상 심볼릭 링크를 만든다
  3. -s 옵션을 주면 심볼릭 링크를, 주지 않으면 하드 링크를 만든다
  4. 하드 링크는 존재하지 않는 대상에도 만들 수 있다
정답과 해설

정답 3번. ln은 기본이 하드 링크이고 -s(--symbolic)를 주면 심볼릭 링크다. 하드 링크를 만들 때는 대상이 반드시 존재해야 한다. 근거 보기

14.crontab 항목 '30 2 * * 1 /backup.sh' 의 실행 시점은?

  1. 매주 월요일 02:30
  2. 매월 1일 02:30
  3. 매일 02:30
  4. 매주 월요일 30분마다 2시간 간격
정답과 해설

정답 1번. 필드 순서는 분 시 일 월 요일이다. 분=30, 시=2, 요일=1(월요일)이므로 매주 월요일 02:30에 실행된다. 요일은 0~7이고 0과 7이 일요일이다. 근거 보기

15.다음 신호 중 프로세스가 잡거나(catch) 무시하거나 막을 수 없어 강제 종료에 쓰이는 것은?

  1. SIGTERM (15)
  2. SIGHUP (1)
  3. SIGINT (2)
  4. SIGKILL (9)
정답과 해설

정답 4번. signal(7)에 따르면 SIGKILL과 SIGSTOP은 잡거나 차단하거나 무시할 수 없다. SIGTERM(15)은 프로세스가 정리 작업을 하도록 처리할 수 있다. x86 번호는 SIGHUP 1, SIGINT 2, SIGKILL 9, SIGTERM 15다. 근거 보기

16.bash에서 'ls /none > out.txt 2>&1' 을 실행한 결과로 옳은 것은? (/none 은 없는 경로)

  1. 오류 메시지가 화면에 출력되고 out.txt 는 비어 있다
  2. 오류 메시지가 out.txt 에 기록된다
  3. out.txt 가 생성되지 않는다
  4. 표준출력만 out.txt 에 기록되고 오류는 사라진다
정답과 해설

정답 2번. 먼저 표준출력을 out.txt로 돌리고, 그다음 2>&1이 표준에러를 '현재 표준출력이 가리키는 곳'으로 복사하므로 오류도 out.txt로 간다. 순서를 바꿔 '2>&1 > out.txt'로 쓰면 오류는 화면에 남는다. 근거 보기

18.systemctl enable nginx 의 효과로 옳은 것은?

20.호스트 192.168.10.77/26 이 속한 네트워크 주소와 브로드캐스트 주소는?

  1. 네트워크 192.168.10.64, 브로드캐스트 192.168.10.128
  2. 네트워크 192.168.10.0, 브로드캐스트 192.168.10.63
  3. 네트워크 192.168.10.64, 브로드캐스트 192.168.10.127
  4. 네트워크 192.168.10.76, 브로드캐스트 192.168.10.127
정답과 해설

정답 3번. /26은 블록 크기가 64이므로 0, 64, 128, 192 경계로 나뉜다. 77은 64~127 블록에 속해 네트워크 .64, 브로드캐스트 .127이고 사용 가능한 호스트는 62개다. 파이썬 ipaddress로 확인했다. 근거 보기

21.TCP 연결 설정(3-way handshake)에서 패킷이 오가는 순서는?
