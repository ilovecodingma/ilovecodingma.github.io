1.도시가스 배관에서 불이 났을 때 가스 밸브를 잠가 불을 끄는 소화 방법은?

  1. 제거소화
  2. 질식소화
  3. 냉각소화
  4. 억제소화

정답 1번. 가연물의 공급을 차단하는 소화 방법이 제거소화이다. 가스 화재의 밸브 차단이 대표 예이다. 근거 보기

2.숯(목탄)이나 코크스가 불꽃 없이 표면에서 산소와 반응하며 타는 연소 형태는?

  1. 표면연소
  2. 증발연소
  3. 분해연소
  4. 확산연소
정답과 해설

정답 1번. 고체 가연물의 표면에서 산소와 직접 반응하는 것이 표면연소이며 목탄·코크스·금속분이 예이다. 증발연소는 파라핀·나프탈렌, 분해연소는 목재·석탄에서 나타난다. 근거 보기

3.공기 중 산소가 없어도 분자 내에 가연 성분과 산소를 함께 가지고 있어 스스로 연소·폭발하는 연소 형태는?

  1. 확산연소
  2. 표면연소
  3. 증발연소
  4. 자기연소

정답 4번. 자기연소는 제5류 위험물(질산에스테르류, 니트로화합물 등)처럼 분자 내 산소를 이용하는 연소이다. 근거 보기

4.같은 가연성 액체에서 인화점, 연소점, 발화점을 낮은 온도부터 순서대로 나열한 것은?

  1. 연소점 < 인화점 < 발화점
  2. 발화점 < 인화점 < 연소점
  3. 인화점 < 발화점 < 연소점
  4. 인화점 < 연소점 < 발화점
정답과 해설

정답 4번. 인화점은 점화원으로 불이 붙는 최저 온도, 연소점은 점화원을 치워도 연소가 계속되는 최저 온도(인화점보다 약간 높음), 발화점은 점화원 없이 스스로 발화하는 최저 온도이다. 근거 보기

5.폭굉과 폭연의 비교로 옳은 것은?

  1. 폭굉은 화염 전파 속도가 음속보다 빠르고 충격파를 동반하며, 폭연은 음속보다 느리다.
  2. 폭굉은 음속보다 느리고 충격파가 없다.
  3. 폭연은 항상 폭굉보다 압력이 높다.
  4. 폭굉과 폭연은 전파 속도로 구별하지 않는다.
정답과 해설

정답 1번. 폭굉은 전파 속도가 약 1,000~3,500 m/s로 음속을 초과하고 충격파를 동반한다. 폭연은 음속 미만이다. 근거 보기

  1. 플래시오버
  2. 롤오버
  3. 보일오버
  4. 백드래프트

7.열전도에서 푸리에 법칙에 따라 열 전달률은 단면적에 비례하고 두께에 반비례한다. 다른 조건은 같고 단면적을 2배, 두께를 절반으로 하면 열 전달률은 몇 배가 되는가?

  1. 2배
  2. 4배
  3. 8배
  4. 16배
정답과 해설

정답 2번. q = k·A·ΔT/L에서 A가 2배, L이 1/2배이면 q는 2×2 = 4배이다. 근거 보기

8.복사열은 절대온도의 4제곱에 비례한다(스테판-볼츠만 법칙). 다른 조건은 같고 물체의 절대온도가 2배가 되면 복사열은 몇 배가 되는가?

  2. 8배
  3. 16배
  4. 32배

9.메탄(연소범위 하한 5.0%) 60%와 프로판(연소범위 하한 2.1%) 40%가 섞인 혼합가스의 연소하한계를 르 샤틀리에 식으로 구한 값은 약 몇 %인가?

  1. 2.1%
  2. 3.2%
  3. 3.8%
  4. 5.0%
정답과 해설

정답 2번. LFL = 100 / (60/5.0 + 40/2.1) = 100 / 31.05 ≈ 3.2%이다. 3.8%는 단순 가중평균으로 잘못 구한 값이다. 근거 보기

10.다음 가스의 연소범위 하한-상한(%)이 수소 4-75, 아세틸렌 2.5-81, 메탄 5-15, 프로판 2.1-9.5이다. 위험도(H=(U-L)/L)가 가장 큰 것은?

11.프로판(C3H8) 2m³를 완전연소시키는 데 필요한 이론 공기량은 약 몇 m³인가?(공기 중 산소 부피비 21%)

  1. 10.0m³
  2. 23.8m³
  3. 47.6m³
  4. 95.2m³
정답과 해설

정답 3번. C3H8 + 5O2 → 3CO2 + 4H2O이므로 프로판 2m³에는 산소 10m³가 필요하고 공기량은 10/0.21 ≈ 47.6m³이다. 근거 보기
