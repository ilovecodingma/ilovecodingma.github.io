  2. 데이터
  3. 지식
  4. 지혜
정답과 해설

16.거래 10건 중 A가 5건, B가 4건, A와 B가 함께 2건 포함된다. 연관규칙 A→B의 신뢰도와 향상도는?

  1. 신뢰도 0.4, 향상도 1.0
  2. 신뢰도 0.5, 향상도 1.0
  3. 신뢰도 0.4, 향상도 2.0
  4. 신뢰도 0.2, 향상도 0.5

정답 1번. 지지도=2/10=0.2, 신뢰도=2/5=0.4, 향상도=0.2/(0.5×0.4)=1.0이다. 향상도 1은 A와 B가 독립이라 규칙이 유용한 연관을 보여 주지 않는다는 뜻이다. 근거 보기

17.이진 분류 결과 TP=40, FP=10, FN=20, TN=30이다. 정밀도(precision)와 재현율(recall)은?

  1. 정밀도 0.80, 재현율 약 0.67
  2. 정밀도 0.67, 재현율 0.80
  3. 정밀도 0.70, 재현율 0.70
  4. 정밀도 0.80, 재현율 0.80
정답과 해설

정답 1번. 정밀도=TP/(TP+FP)=40/50=0.8, 재현율=TP/(TP+FN)=40/60≈0.67이다. 정확도는 (40+30)/100=0.7이다. 근거 보기
