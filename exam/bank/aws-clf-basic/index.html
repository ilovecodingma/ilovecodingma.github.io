AWS Cloud Practitioner 핵심 개념 문제은행 공식 자료 기반 유사문제

출처: AWS Certified Cloud Practitioner (CLF-C02) 공식 시험 가이드 / AWS 공식 문서 · 이용 조건: 기출 접근 불가로 공식 시험 가이드와 AWS 문서를 근거로 직접 작성

이 문제는 기출 원문이 아니라 공식 자료(법령·공고)를 근거로 실제 시험과 비슷한 유형으로 새로 쓴 유사문제예요. 실제 시험 문제와 다르고, 법령은 바뀔 수 있어 시험 전에 공식 자료로 한 번 더 확인하세요.

전체 문제 보기

1.AWS 공동 책임 모델에서 고객의 책임에 해당하는 것은?

  1. 하이퍼바이저 소프트웨어 관리
  2. AWS 데이터 센터 건물의 물리적 출입 통제
  3. EC2 인스턴스에 설치된 게스트 운영체제의 보안 패치
  4. 글로벌 인프라를 구성하는 네트워크 장비 교체
정답과 해설

정답 3번. AWS 는 클라우드 자체의 보안(시설·하드웨어·하이퍼바이저)을, 고객은 클라우드 안의 보안(게스트 OS·데이터·접근 권한)을 맡는다. 근거 보기

2.AWS Well-Architected Framework 의 6개 기둥에 포함되지 않는 것은?

  1. 확장성(Scalability)
  2. 보안
  3. 안정성
  4. 지속 가능성
정답과 해설

정답 1번. 여섯 기둥은 운영 우수성, 보안, 안정성, 성능 효율성, 비용 최적화, 지속 가능성이다. 근거 보기

3.AWS 가용 영역(Availability Zone)에 대한 설명으로 옳은 것은?

  1. 리전과 같은 말이다
  2. 전 세계 어디서나 콘텐츠를 캐시하는 엣지 위치이다
  3. 하나의 데이터 센터 안의 서버 랙 한 줄이다
  4. 한 리전 안에서 물리적으로 분리된 하나 이상의 데이터 센터 묶음이다
정답과 해설

정답 4번. 리전은 여러 가용 영역으로 구성되며, 가용 영역은 전원·네트워크가 분리되어 장애를 격리한다. 근거 보기

4.Amazon S3 Standard 스토리지 클래스가 설계한 객체 내구성 수준은?

  1. 99.9%
  2. 99.999999999% (11 나인)
  3. 99.99%
  4. 99.999%
정답과 해설

정답 2번. S3 Standard 는 연간 99.999999999% 내구성을 목표로 여러 가용 영역에 데이터를 저장한다. 근거 보기

5.EC2 인스턴스에 연결해 부팅 디스크처럼 쓰는 블록 스토리지 서비스는?

  1. Amazon S3
  2. Amazon EBS
  3. Amazon Glacier
  4. Amazon Route 53
정답과 해설

정답 2번. EBS 는 EC2 에 붙이는 블록 볼륨이고 S3 는 객체 스토리지다. 근거 보기

6.AWS 계정의 루트 사용자 보호를 위한 모범 사례로 옳은 것은?

  1. 루트 비밀번호를 팀 메신저에 공유한다
  2. 루트 액세스 키를 만들어 개발자에게 공유한다
  3. 루트 사용자로 모든 일상 작업을 한다
  4. 루트 사용자에 MFA 를 켜고 일상 작업은 IAM 자격으로 한다
정답과 해설

정답 4번. 루트 사용자는 계정의 모든 권한을 가지므로 MFA 로 보호하고 일상 작업에는 쓰지 않는다. 근거 보기

7.사용자에게 업무에 필요한 권한만 부여하고 그 이상은 주지 않는다는 보안 원칙은?

  1. 최소 권한 원칙
  2. 직무 분리 해제 원칙
  3. 권한 상속 확대 원칙
  4. 공용 계정 원칙
정답과 해설

정답 1번. IAM 정책은 필요한 작업과 리소스에만 허용하는 최소 권한을 따라야 한다. 근거 보기

8.서버를 프로비저닝하거나 관리하지 않고 이벤트가 발생할 때만 코드를 실행하는 서비스는?

  1. Amazon Lightsail
  2. Amazon EC2
  3. AWS Lambda
  4. AWS Snowball
정답과 해설

정답 3번. Lambda 는 서버리스 컴퓨팅 서비스이며 실행한 시간과 요청 수만큼 비용을 낸다. 근거 보기

9.완전 관리형 키-값 NoSQL 데이터베이스 서비스는?

  1. Amazon Aurora
  2. Amazon RDS
  3. Amazon Redshift
  4. Amazon DynamoDB
정답과 해설

정답 4번. DynamoDB 는 NoSQL, RDS·Aurora 는 관계형, Redshift 는 데이터 웨어하우스다. 근거 보기

10.전 세계 엣지 로케이션에 콘텐츠를 캐시해 사용자 지연 시간을 줄이는 서비스는?

  1. Amazon Route 53
  2. Amazon CloudFront
  3. AWS Direct Connect
  4. Amazon VPC

정답 2번. CloudFront 는 콘텐츠 전송 네트워크(CDN) 서비스다. 근거 보기

12.VPC 에서 서브넷 수준에 적용되며 상태를 저장하지 않는(stateless) 방화벽 기능은?

13.중단되어도 괜찮은 대규모 배치 작업을 가장 저렴하게 처리하려는 상황에 적합한 EC2 구매 옵션은?
