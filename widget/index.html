🧩 공모전 위젯 무료 — 블로그에 이번 주 마감 공모전 자동 표시

루리
블로그·카페에 붙이면 이번 주 마감 공모전이 매시간 알아서 바뀌어요. 회원가입도, 비용도 없어요!

루리의 줍줍이 매시간 정리하는 마감 공모전·지원금·핫이슈 목록을 내 블로그나 카페, 홈페이지에 그대로 띄울 수 있는 무료 위젯이에요. 공모전·대외활동 정보를 올리는 블로그라면 글마다 목록을 새로 쓰지 않아도 돼요. 위젯 안에는 광고가 없고, 항목을 누르면 루리의 줍줍 상세 페이지(마감·상금·자격·준비 일정)로 이동해요.

2. 미리보기

3. 붙이는 코드

🖼️ 이미지 + 링크 (네이버 블로그·카페·디시)

🪟 iframe (티스토리·워드프레스·홈페이지)

텍스트 목록은 복사한 그 시점의 목록이라 자동으로 바뀌지 않아요.

📗 네이버 블로그 사이드바에 붙이는 법 (캡처)

네이버 블로그용 코드 (가로 170px 세로형)

  1. 1. 블로그 관리 → 꾸미기 설정

    네이버 블로그 오른쪽 위 「관리」로 들어가 위쪽 「꾸미기 설정」 탭을 누르고, 왼쪽 「레이아웃·위젯 설정」을 고르세요.

  2. 2. 디자인 설정 → 레이아웃·위젯 설정

    레이아웃 화면 오른쪽에 「위젯 사용 설정」 목록이 있어요. 아래로 내려 주세요.

  3. 3. 위젯 목록 아래 「+위젯직접등록」

    위젯 목록 맨 아래 「+위젯직접등록 BETA」 버튼을 눌러요.

  4. 4. 위젯명 입력

    위젯 이름은 블로그에 보이지 않으니 알아보기 쉽게 「이번 주 마감 공모전」처럼 적어요.

  5. 5. 위젯 코드 붙여넣기 → 다음

    위에서 복사한 「네이버 블로그용 코드」를 위젯 코드 칸에 붙여 넣고 「다음」을 눌러요.

  6. 6. 미리보기 확인 → 등록

    미리보기에 위젯 그림이 보이면 「등록」을 눌러요. 네이버 위젯은 가로 170px까지만 보여서 170px 전용 이미지를 써요.

  7. 7. 사이드바에 위젯 블록이 생겨요

    왼쪽 사이드바에 새 위젯 블록이 생겨요. 원하는 위치로 끌어 옮긴 뒤 아래 「적용」 → 「확인」을 눌러요.

  8. 8. 블로그에서 확인

    내 블로그에 들어가면 사이드바에 위젯이 보여요. 누르면 루리의 줍줍 「이번 주 마감 공모전」으로 이동해요.

  9. 9. 위젯 확대 모습

    이미지는 매시간 새로 그려요. 다만 네이버가 이미지를 저장해 둘 수 있어서, 목록이 오래 그대로면 위젯을 지웠다가 다시 등록해 주세요.

블로그에 붙이는 법

  • 네이버 블로그 사이드바: 위의 캡처 매뉴얼대로 「위젯직접등록」에 네이버용 코드를 넣어요.
  • 네이버 블로그 글: 글쓰기 → 사진 대신 「이미지 주소 복사」로 받은 주소를 이미지로 넣고, 이미지를 눌러 링크에 https://sungprofile.cloud/contest/?src=w_img 를 걸어요. 네이버 에디터는 붙인 이미지를 네이버 서버에 복사해 두기 때문에 자동 갱신은 안 될 수 있어요. 목록이 바뀌면 다시 붙이거나, 프로필·위젯 영역에 링크로 걸어 두세요.
  • 티스토리: 글쓰기 → 기본모드 오른쪽 위 「HTML」로 바꾸고 iframe 코드를 붙여요. 사이드바에 넣으려면 꾸미기 → 사이드바 → HTML 배너 출력에 붙여요.
  • 워드프레스: 블록 추가 → 「사용자 정의 HTML」 블록에 iframe 코드를 붙여요. 위젯 영역(외모 → 위젯)에도 같은 블록을 쓸 수 있어요.
  • 네이버 카페·디시: iframe 이 막혀 있어서 이미지 + 링크 방식이 좋아요. 이미지 주소로 그림을 넣고 아래에 사이트 링크를 한 줄 적어 주세요.

위젯 목록은 매시간 갱신돼요. 공모전 정보는 각 주최 기관 공고를 정리한 것이라, 응모 전 공식 공고를 꼭 확인하세요. 위젯을 붙인 뒤 문제가 있으면 문의로 알려 주세요.
