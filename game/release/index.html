출시일이 안 정해진 게임은?
스팀에 「2026년 10월」「2026년」처럼 날짜가 흐리게 적힌 게임은 일부러 뺐어. 날짜가 정해지면 이 목록에 자동으로 들어와.
에픽 게임즈 스토어 출시 일정도 있어?
에픽은 출시 예정작 날짜를 공개 자료로 안 내줘서 이 페이지엔 스팀만 있어. 에픽은 매주 바뀌는 무료 게임 예고를 무료 게임 기록에 정리해.
