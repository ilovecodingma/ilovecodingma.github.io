ProxmoxでImmichをZFSミラーで構築:セットアップと3-2-1バックアップ

公開日 2026-10-27

Immichは、スマートフォンからのバックアップに対応した、セルフホスト型の写真・動画ライブラリです。このガイドでは、ディスク故障に耐える構成を紹介します。Proxmox上のVMでImmichを動かし、写真はZFSミラーに置き、その上に本格的な3-2-1バックアップを組みます。Proxmoxがすでにインストール済みで、ミラー用に同容量のディスクが2台あることを前提とします。

ハードウェア:公式の最小要件

項目最小推奨
RAM6 GB8 GB
CPU2コア4コア
データベースのストレージローカルSSD。ネットワーク共有は不可

出典:Immich requirements(ページ更新日 2026-10-08、確認日 2026-10-19)。同ページには、サムネイルとトランスコード済み動画でライブラリのサイズが約10〜20%増えること、RAMが4 GBしかない場合は機械学習を無効にすべきことも記載されています。

ステップ1 — ZFSミラーを作る

  1. ProxmoxでDatacenter → node → Disks → ZFS → Create: ZFSを開き、2台のディスクを選んでRAIDレベルにMirrorを指定します。
  2. 2台構成のミラーで使える容量は1台分です。どちらか1台が故障してもデータは失われません。
  3. VMディスク用のストレージとして追加するか、データセット(例:tank/photos)を作ってVMに渡します。

ステップ2 — VMを作る

  1. 上の最小要件を満たすDebianまたはUbuntuのVMを作ります。PostgresのデータベースをローカルSSDに置くため、VMのシステムディスクはSSDにします。
  2. CPUタイプはhost(またはx86-64-v2に対応する他のタイプ)にします。Immichの機械学習コンテナは、amd64上でx86-64-v2を必要とします。
  3. 写真用に、ZFSミラー上に2つ目の仮想ディスクを追加し、たとえば/srv/photosにマウントします。

Immichの公式ドキュメントが想定しているのは、VM内でのDocker Composeです。LXCコンテナ内での実行は推奨されないと説明されています。

ステップ3 — Immichをインストールする

  1. DockerとComposeプラグインをインストールします。
  2. Immichのインストール手順のドキュメントから、公式のdocker-compose.ymlとexample.envをダウンロードします。
  3. .envでUPLOAD_LOCATION=/srv/photos/libraryを設定し、DB_DATA_LOCATIONはSSDのシステムディスク上に残します。
  4. docker compose up -dを実行し、ポート2283を開いて管理者アカウントを作成し、スマートフォンアプリをインストールしてバックアップをオンにします。

ステップ4 — 3-2-1バックアップ

ミラーが守るのはディスクの故障であり、誤削除、ランサムウェア、火災からは守れません。Immich自身のドキュメントも3-2-1戦略を推奨しています。コピーを3つ、媒体は2種類、うち1つはオフサイトに置く、というものです。

コピー場所方法
1ZFSミラー(稼働中)Immich本体
2外付けUSBディスクまたは別のマシンZFSスナップショット+zfs send、またはrestic/borg
3オフサイト(クラウドのバケットや友人のサーバー)暗号化したrestic/borg

両方を必ずバックアップしてください。ImmichはデータベースのダンプをUPLOAD_LOCATION/backupsに自動作成します(デフォルトは毎日午前2:00、直近14個を保持)。このダンプに含まれるのはメタデータだけで、写真は含まれません。したがってバックアップジョブはUPLOAD_LOCATION全体をコピーする必要があり、そうすればダンプも含まれます。出典:Immich backup and restore、2026-10-19確認。

復元は一度テストしてください。使い捨てのVMを立ち上げ、ファイルとダンプを復元して、ログインできることを確かめます。

同じサーバーに載せられるもの

  • 同じミラー上のファイル同期サービス(例:Syncthing)。
  • パスワードマネージャーのサーバー。同じオフサイトのジョブでバックアップします。
  • 監視(ディスクのSMARTとZFS scrubのアラート)。この一覧で最も安上がりな保険です。

FAQ

ミラーはバックアップですか?
いいえ。冗長化です。写真を削除すると、2台のディスクの両方から即座に消えます。
データベースをNFS経由でZFSミラーに置けますか?
Immichは、データベースをネットワーク共有に置いてはならないとしています。ローカルSSDに置いてください。
ZFS自体にはどれくらいのRAMが必要ですか?
ZFSは空きRAMをキャッシュ(ARC)として使い、メモリ不足になれば返します。まずVMのRAMを確保し、残りをホストに使わせてください。
