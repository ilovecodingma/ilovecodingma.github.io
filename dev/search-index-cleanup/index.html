1인+AI로 사이트 만들며 배운 것: 페이지 줄이고 검색 색인 정리하기

#검색·SEO #정적 사이트 #AI 에이전트

30초 요약

사람 한 명과 Claude Code로 만든 정보 사이트에서 이틀 동안 페이지 3,744개를 863개 수준으로 줄이고 얇은 페이지를 데이터 화면으로 합친 기록과 규칙.

이 글의 목차
  1. 무엇이 문제였나
  2. 바꾼 것과 숫자
  3. 얇은 페이지를 고른 규칙
  4. AI에게 맡길 때 조심한 점
  5. 자주 묻는 것

사람 한 명과 AI(Claude Code)로 정보 사이트를 만들다 보면 페이지는 금방 수천 개로 불어나요. 공고 하나, 키워드 하나마다 자동으로 페이지가 생기니까요. 그런데 검색엔진은 페이지 수를 반기지 않았어요. 이 글은 이틀 동안 페이지를 줄이고 검색 색인을 정리하면서 실제로 바꾼 것과 숫자를 기록한 거예요. 숫자는 모두 이 사이트 저장소의 커밋 기록에서 다시 센 값이에요(기준일 2026-10-19).

1English summary2관련 글3출처

무엇이 문제였나

  • 예전 프로젝트에서 남은 영어·일본어·중국어 자동 번역 페이지가 언어마다 810개씩 있었어요. 내용은 한국어 원문을 기계로 옮긴 것뿐이었어요.
  • 지원금 공고(/a/), 인기 키워드(/kw/), 수상 분석(/lab/) 상세 페이지 가운데 고유한 본문이 거의 없는 「얇은」 페이지가 많았어요.
  • 서치 콘솔에 사이트맵을 내도 색인된 페이지는 0으로 나왔어요(10/19 09:59 조회, 제출 691개).

바꾼 것과 숫자

시각한 일전후
10/18 17:02옛 다국어 페이지(en·ja·zh 각 810개)와 옛 이동 페이지 삭제전체 페이지 3,7441,311
10/18 20:52고유 본문 200자 미만 상세 페이지를 검색 제외(noindex)로 돌리고 사이트맵에서 뺌사이트맵 1,329615
10/19 11:18검색 제외된 얇은 페이지는 파일을 아예 만들지 않고 데이터 화면 하나로 합침(/a/ 474개, /kw/ 202개, /lab/ 51개 등)전체 페이지 1,446863

「전체 페이지」는 저장소의 index.html 개수, 「사이트맵」은 sitemap.xml 의 주소 수예요. 10/19 오후에 레시피 1,000개를 새로 넣어서 지금 사이트맵 숫자는 다시 늘었어요.

얇은 페이지를 고른 규칙

  1. 빌드가 끝나면 상세 페이지마다 공통 머리·꼬리를 빼고 고유한 본문 글자 수를 세요.
  2. 200자 미만이면 자동으로 검색 제외(noindex)로 돌려요.
  3. 검색 제외된 페이지는 다음 빌드부터 파일을 만들지 않아요. 대신 /apply/?id=…처럼 데이터를 불러오는 화면 하나가 같은 내용을 보여 줘요.
  4. 예전 주소로 들어오면 404 페이지가 같은 규칙으로 새 주소로 바로 넘겨 줘요. 사이트 안 링크도 빌드 때 새 주소로 바꿔요.
  5. 마감된 공모전 안내처럼 검색에 남아야 하는 페이지는 이 규칙에서 빼요.

AI에게 맡길 때 조심한 점

  • 지우기 전에 숫자부터: 「얼마나 줄었나」를 말로 받지 않고 커밋별로 파일 수를 다시 셌어요. 이 글의 숫자도 그렇게 셌어요.
  • 규칙은 코드로: 「얇은 페이지 지워 줘」 대신 「고유 본문 200자 미만」처럼 다시 돌려도 같은 결과가 나오는 기준을 만들게 했어요.
  • 옛 주소 처리: 페이지를 지우면 외부 링크가 404가 돼요. 지우기 전에 이동 규칙부터 넣었어요.

자주 묻는 것

페이지를 줄이면 검색 유입이 줄지 않나요?
지운 건 고유 내용이 거의 없는 페이지예요. 같은 정보는 데이터 화면과 상위 목록에 그대로 있어요. 효과는 서치 콘솔 색인 수로 계속 확인하고 있어요.
200자 기준은 어디서 왔나요?
공식 기준은 없어요. 이 사이트의 상세 페이지 분포를 보고 정한 내부 기준이에요.

이어지는 글: 신규 도메인 백링크·홍보 채널 사흘 실측 정리 — 색인 0에서 밖으로 링크를 늘린 기록이에요.

1English summary

A solo developer and an AI coding agent built a Korean information site and watched the page count balloon to 3,744 as auto-generated pages piled up, while Google Search Console showed zero indexed pages from 691 submitted URLs. In two days the pages were cut to about 863 by deleting old machine-translated language copies and merging thin detail pages into one data view, and the sitemap was trimmed to match. The post lists the exact changes, the numbers (recounted from commit history), and the rules that came out of it.
